# 腾讯招聘首页 (join.qq.com) UI/UX 逆向工程与原型设计规范

本文档针对 `https://join.qq.com/`（腾讯招聘首页）的视觉与结构特征进行逆向工程分析，并从软件工程视角输出专业原型设计需求。文档采用正式（Formal）风格，尺寸与样式参数以 LaTeX 语法表述，核心需求以标准 Markdown 表格呈现，便于直接复制至 Axure、Figma 或 Confluence 等协作工具中。

::: tip 用途
本文分为四部分：概述、视觉与交互设计规范、原型设计白板位置需求、软件工程实现建议。前三部分面向 UI/UX 设计师与原型设计师，最后一部分面向前端工程师。
:::

---

## 1. 概述 (Overview)

本文档旨在对腾讯招聘首页的核心视觉元素（卡片尺寸、圆角、质感、排版）进行结构化拆解，并转化为可供前端开发与 UI/UX 设计师直接执行的原型设计需求。文档基于现代 Web 设计系统（如 TDesign）的通用规范，结合 8px 栅格系统（8px Grid System）进行参数化定义。

---

## 2. 视觉与交互设计规范 (Visual & Interaction Design Specifications)

### 2.1 卡片规格 (Card Specifications)

首页核心内容（如"招聘项目"、"加入腾讯的 N 个理由"）均采用卡片式布局。其几何参数定义如下：

- **容器总宽**：$W_{container} = 1200\text{px}$（居中布局，左右外边距 $Margin_{auto}$）。
- **栅格列数**：招聘项目模块采用 $4$ 列栅格，"N 个理由"模块采用 $3$ 列栅格。
- **卡片宽度**：$W_{card} = \frac{W_{container} - (N - 1) \times G_{gap}}{N}$。其中 $N$ 为列数，$G_{gap} = 24\text{px}$ 为列间距。
  - 4 列卡片宽度：$W_{card\_4} = 282\text{px}$
  - 3 列卡片宽度：$W_{card\_3} = 384\text{px}$
- **卡片高度**：自适应内容高度 ($H = \text{auto}$)，但同一行内的卡片需通过 Flexbox 或 Grid 的 `align-items: stretch` 保持等高。
- **内边距 (Padding)**：$P_{card} = 32\text{px}$（上下左右一致，确保呼吸感）。

### 2.2 圆角与质感 (Border Radius & Material Texture)

- **圆角半径**：统一采用 $r = 12\text{px}$，以传递现代、亲和且专业的视觉感受。
- **背景色**：$Background_{card} = \#FFFFFF$。
- **默认阴影 (Default Shadow)**：$S_{default} = 0\ 4\text{px}\ 12\text{px}\ \text{rgba}(0, 0, 0, 0.05)$，提供轻微的层级悬浮感。
- **悬停质感 (Hover State)**：触发 `:hover` 伪类时，执行以下状态转移：
  1. 垂直位移：$\Delta y = -4\text{px}$（向上微动）。
  2. 阴影加深：$S_{hover} = 0\ 8\text{px}\ 24\text{px}\ \text{rgba}(0, 0, 0, 0.10)$。
  3. 过渡动画：$Transition = \text{all}\ 0.3\text{s}\ \text{cubic-bezier}(0.4, 0.2, 1)$。

### 2.3 排版系统 (Typography & Layout)

遵循严格的字体层级（Type Hierarchy）与色彩规范：

- **主标题 (H2/H3)**：$Font\text{-}size = 24\text{px}$，$Font\text{-}weight = 600$，$Color = \#111111$，$Line\text{-}height = 32\text{px}$。
- **副标题/标签 (Label)**：$Font\text{-}size = 14\text{px}$，$Font\text{-}weight = 500$，$Color = \#0052D9$（腾讯品牌蓝），用于如"校招"、"青云计划"等标识。
- **正文描述 (Body)**：$Font\text{-}size = 14\text{px}$，$Font\text{-}weight = 400$，$Color = \#666666$，$Line\text{-}height = 22\text{px}$。
- **操作按钮 (CTA Button)**：如"立即投递"，采用幽灵按钮（Ghost Button）或实心主色按钮，$Border\text{-}radius = 4\text{px}$，$Padding = 8\text{px}\ 24\text{px}$。

## 4. 软件工程视角的实现建议 (Software Engineering Implementation Guidelines)

作为软件工程师，在将上述原型转化为生产级代码时，建议采用以下架构与实践：

### 4.1 组件化架构 (Componentization)

- **原子设计 (Atomic Design)**：将 UI 拆分为 `Button`、`Typography`、`Icon` (Atoms)，组合成 `Card`、`ListItem` (Molecules)，最终构建 `RecruitmentGrid`、`FeatureSection` (Organisms)。
- **Props 接口定义**（以 TypeScript 为例）：

```typescript
interface CardProps {
  title: string;
  description: string;
  tag?: string; // 如 "校招"
  ctaText: string;
  ctaLink: string;
  hoverElevation?: number; // 控制阴影层级
}
```

### 4.2 样式工程化 (Styling Engineering)

- 推荐使用 **Tailwind CSS** 或 **CSS Modules** 以避免全局样式污染。
- 阴影与圆角应定义为 CSS 变量（Custom Properties），便于全局主题切换：

```css
:root {
  --card-radius: 12px;
  --shadow-default: 0 4px 12px rgba(0, 0, 0, 0.05);
  --shadow-hover: 0 8px 24px rgba(0, 0, 0, 0.10);
  --transition-base: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}
.card {
  border-radius: var(--card-radius);
  box-shadow: var(--shadow-default);
  transition: var(--transition-base);
}
.card:hover {
  transform: translateY(-4px);
  box-shadow: var(--shadow-hover);
}
```

### 4.3 响应式与性能优化 (Responsive & Performance)

- **响应式断点**：使用 CSS Grid 的 `auto-fit` 和 `minmax` 实现无缝响应式，避免过多的 Media Queries：

$$
\text{grid-template-columns: repeat(auto-fit, minmax}(280\text{px}, 1\text{fr}))
$$

- **性能优化**：
  1. 对 Hero 区域的背景图使用现代格式（WebP / AVIF）并实施懒加载（Lazy Loading）。
  2. 悬停动画应仅作用于 `transform` 和 `opacity` 属性，以触发 GPU 硬件加速，避免触发重排（Reflow）。

::: tip 落地建议
在流量敏感场景下，背景图懒加载与 GPU 加速动画是性价比最高的两项优化，应优先实施。
:::
