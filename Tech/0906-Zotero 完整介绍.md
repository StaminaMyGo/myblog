# Zotero 完整介绍

Zotero 是一款免费开源的文献与参考文献管理软件，由非营利机构 Corporation for Digital Scholarship 开发，面向学生和科研人员，覆盖文献采集、整理、阅读批注、引文生成、笔记管理与多端同步的完整工作流。

::: tip 定位说明
Zotero 不只是文献库，也可作为个人知识库使用，能够与 Obsidian、Notion 等笔记软件对接，适合长期积累文献与知识。
:::

## 基础信息

- **平台**：Windows / macOS / Linux 桌面客户端；浏览器扩展（Chrome / Firefox / Edge）；iOS；网页版；Android 第三方客户端。
- **授权**：开源，核心功能永久免费；元数据（条目、标签、笔记）同步无限免费；官方文件（如 PDF 附件）免费配额为 300MB，超出后可付费扩容，或对接 WebDAV（如坚果云）实现不限空间的附件同步。
- **定位**：文献管理、PDF 阅读批注、学术笔记、引文生成，同时可作为个人知识库，可对接 Obsidian / Notion 等笔记软件。

## 核心功能

### 一键抓取文献元数据

- 安装浏览器插件 Zotero-Connector 后，浏览知网、IEEE Xplore、arXiv、Web of Science 及图书馆页面时，点击浏览器图标即可自动抓取作者、标题、期刊、年份、DOI，并可同时保存 PDF 与网页快照。
- 将本地 PDF 拖拽进软件，可自动检索并补全文献信息。

### 文献库组织管理

- **集合（Collections）**：层级文件夹结构，用于按项目或主题分类。
- **标签（Tags）**：多维度打标，一篇文章可归属多个标签。
- **智能检索（Saved Search）**：通过设置筛选条件自动生成动态文献集合。
- **全文检索**：对 PDF 正文、笔记与元数据进行统一搜索定位。

### PDF 阅读与批注（Zotero 6 起内置阅读器）

- 支持高亮、文本注释、区域批注与图片标记。
- 批注可自动生成笔记，笔记内可插入引用。
- 批注跟随条目同步，多设备互通。
- 笔记支持 Markdown 基础语法，可导出为适配 Obsidian 的格式。

### 引文与参考文献生成

- 提供 Word / LibreOffice / Google Docs 插件，写作时直接插入引用，一键生成参考文献列表。
- 内置 9000 余种引用格式，覆盖 APA、GB/T-7714、MLA、Chicago 及各期刊自定义格式；可随时切换格式并批量更新参考文献。
- 支持导出 BibTeX / BibLaTeX，适配 LaTeX 写作（配合 Better-BibTeX 插件）。

### 同步与协作

- **数据同步**：文献条目、笔记、标签无限免费同步。
- **文件同步**：PDF 附件官方配额 300MB，可配置 WebDAV（如坚果云）实现不限空间的文件同步。
- **群组库**：多人共享文献库，支持协同批注与共建参考文献列表。

## 高频必备插件

| 插件 | 用途 |
|------|------|
| Better-BibTeX | LaTeX / BibTeX 导出，稳定 key 生成，科研论文写作必备 |
| ZotFile | PDF 重命名、附件迁移，配合坚果云 WebDAV 优化同步 |
| Notero | 将 Zotero 条目与笔记同步到 Notion |
| Zotero-Obsidian | 打通 Zotero 与 Obsidian 的双向链接 |
| PanAttach-Sync | 对接百度网盘同步附件（替代 WebDAV） |

## 优点与局限

### 优点

- 完全开源，数据归用户所有，无厂商锁定风险。
- 浏览器抓取能力较强，中英文文献识别效果较好。
- 离线可用，以本地数据库为主，网络条件较差时仍可正常工作。
- 插件生态丰富，支持高度自定义。
- 笔记、批注、文献、引文一体化，覆盖完整科研链路。

### 局限

- 初次上手存在一定学习成本。
- 官方附件存储空间有限，国内使用通常需要搭配坚果云等 WebDAV 服务。
- 文献量达到上万条时，搜索与同步可能产生性能压力。
- Android 无官方客户端，只能使用第三方应用。

## 与 Mendeley 的对比

| 维度 | Zotero | Mendeley |
|------|--------|----------|
| 开源 | 开源、本地优先、高度自定义 | 闭源 |
| 定位 | 适合长期管理文献、LaTeX 用户、需要对接外部笔记工具的用户 | Elsevier 旗下，云优先，具备 AI 阅读能力，与出版社数据库深度绑定 |

## 适合的工作流（软件工程 / 科研场景）

1. 浏览器阅读论文，使用 Connector 一键保存到 Zotero。
2. 在 Zotero 内置阅读器中批注，并撰写阅读笔记。
3. 使用插件将笔记导出或同步到 Obsidian，形成文献知识库。
4. 写作论文时，由 Word / LaTeX 调用 Zotero 生成 GB/T-7714 格式的参考文献。

::: warning 使用提示
Zotero 的官方附件存储配额有限，若需长期保存大量 PDF 附件，建议提前配置 WebDAV 或第三方网盘同步方案，避免附件数据迁移。
:::
