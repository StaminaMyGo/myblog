# 乐理的物理本质：从泛音共振到十二平均律

::: tip 一句话总结
乐理不是一套约定俗成的符号规则，而是**频率之间整数比关系**在人耳听感上的投影。本文以"泛音"为核心，把乐理（音符怎么选）、乐谱（音符怎么记）、乐器（怎么上手）三块串成一条物理主线。
:::

内容分三部分：

1. **乐理**：深挖泛音，讲清乐理的本质，目标是触类旁通。
2. **乐谱**：谈视唱练耳，通过改变日常听歌、唱歌的习惯，像学吹口哨一样自然习得。
3. **乐器**：推荐钢琴与吉他的快速入门路径。

## 一、声音的物理基础

### 1.1 声源、传播与两个技术指标

声音由**声源振动**引起，振动通过空气（介质）向四周传播，引起耳鼓膜振动，人就听到了声音。描述振动有两个核心物理量：

| 物理量 | 定义 | 主观感受 |
| :--- | :--- | :--- |
| 频率 | 每秒声波振动的次数，单位 Hz | 主导**音高**（低 = 低沉缥缈，高 = 高亢激越） |
| 振幅 | 振动的幅度，对应声压/声功率 | 主导**音量**（响度） |

::: note 一个直观对照
别针落地：音量小、频率高；迪厅舞曲：音量大、频率低。频率与音量是两条独立的轴，二者互不决定。
:::

### 1.2 人耳的听觉边界

- **频率范围**：20 Hz – 20000 Hz。超出此区间，无论音量多大都听不到。
- **声压范围**：约 20 μPa – 2×10⁸ μPa，最大功率差达 **10⁷ 倍**。

直接用功率表示音量太不方便（若别针落地记为 1 cm，则迪厅约相当于 30 km），因此音量改用**指数单位分贝（dB）**。

::: warning 分贝的口径
分贝是**比值单位**：只能说"这个声音比那个高/低 20 dB"，不能说"这个声音就是 20 dB"（必须说明参考基准）。
:::

### 1.3 人耳舒适区与钢琴

- 听觉舒适区间约 **100 Hz – 4000 Hz**，这恰好就是钢琴的频率范围，这也是钢琴被称为"乐器之王"的原因之一。
- 其他乐器的频率范围更窄，且几乎都落在钢琴范围之内。

## 二、乐音的本质：基音与泛音

### 2.1 自然界没有纯音

自然界不存在单一频率的声音（纯正弦波只能在精密实验室中产生）。听到的所有声音都是**多个频率叠加**的结果：

- **噪音**：各频率的能量杂乱无章，没有任何一个频率占绝对优势，无固定音高感。
- **乐音**：拥有一条**整齐的频率序列**，既有清晰音高，又有独特音色。

### 2.2 泛音列（Harmonic Series）

以一个 400 Hz 的乐音为例，它实际包含的频率是：

```
400, 800, 1200, 1600, 2000, ... Hz
```

即**基频的整数倍**序列。

| 成分 | 名称 | 能量特征 | 人耳感知 |
| :--- | :--- | :--- | :--- |
| 400 Hz | **基音 / 基频** | 能量占绝对优势 | 决定**音高** |
| 800, 1200, 1600… Hz | **泛音**（谐音/和声） | 频率越高能量越弱 | 决定**音色** |

::: important 两个关键推论
1. **去掉泛音，所有乐器听起来都一样。** 把不同乐器弹奏的同一个 400 Hz 音的泛音全部滤掉，只剩 400 Hz 基频，听到的将是完全相同的"嘟"声。能分辨钢琴、吉他、小提琴，靠的就是每种乐器**独有的泛音能量比例**。
2. **去掉基音，音高仍然在。** 实验中把 400 Hz 全部滤掉、只放泛音，人耳依然感知为 400 Hz 的音高——音高感知是大脑从泛音列反推出来的。
:::

### 2.3 为什么"好听"：泛音共振

两个不同音高的乐音相继或同时出现时，如果它们的**泛音列在某个频率上重合**，该频率就会因共振（共鸣）而被强化，听感上和谐、悦耳。

举例：400 Hz 与 600 Hz：

- 400 Hz 的泛音列：400, 800, **1200**, 1600, 2000, …
- 600 Hz 的泛音列：600, **1200**, 1800, …
- 公共泛音 = 1200 Hz → 共振 → 和谐。

::: tip 和弦的本质
**和弦 = 同时弹奏至少三个不同音高的音符。** 它之所以丰满好听，依然是因为多个音的泛音列相互重叠、彼此共振。理解了泛音，再复杂的和弦也能拆解为同一原理。
:::

## 三、音符是怎么选出来的

### 3.1 人耳对音高是"乘法感知"

人耳对频率差的感受是**等比**关系，不是等差关系：

- 100→200 Hz、150→300 Hz、200→400 Hz，听起来音程相同（都是 ×2）。
- 100→120 Hz 与 120→144 Hz 听起来音程也相同（都是 ×1.2）。

也就是说，**音高轴是对数轴**，判断两个音"相距多远"看的是频率比，而不是频率差。

### 3.2 第一步：泛音列上的天然音

从 50 Hz 起按 ×2 取音，得到：

```
50, 100, 200, 400, 800, 1600, 3200, ...
```

这些音相邻任意两个的频率比都是 2，泛音最容易共振。但它们间距太大，整个舒适频段只剩寥寥几个音，必须在中间再插入新音。

### 3.3 第二步：在八度内部细分

以 100→200 Hz 这个"八度"为例：

- **中点 150 Hz**：与 100、200 都构成和谐的泛音关系。
- **1/3 点 133.33 Hz**（≈ 100 × 4/3）：与 100、200 也和谐，但与 150 之间开始出现不和谐。

于是把 **133.33 → 150 Hz** 这一段定为一个最小和谐单位——**全音**。其频率比为：

```
150 / 133.33 ≈ 9 / 8 = 1.125
```

接着发现：

- 100 → 133.33 的音程 ≈ 2.5 个全音（等比意义下的 2.5 次方），可拆成 **2 个全音 + 1 个半音**；
- 150 → 200 的音程同样 ≈ 2.5 个全音，也拆成 **2 全音 + 1 半音**。

这样一个八度内共得到 **7 个音**，相邻关系为：

> **全 – 全 – 半 – 全 – 全 – 全 – 半**（"全全半，全全全半"）

这套由泛音自然导出的音阶，称为**自然大调式音阶**。高一个八度的音 = 低八度同位置音频率的 ×2，因此音阶可以在整个频率轴上复制平移。

### 3.4 不同调式：选音算法的分歧

调式 = 在一个八度内挑音、规定相邻音程关系的算法。

| 调式 | 音程结构 | 特点 |
| :--- | :--- | :--- |
| 自然大调式 | 全 全 半 全 全 全 半 | 西方主流，含半音 |
| 中国五声调式（宫商角徵羽） | 全 全 1.5全 全 1.5全 | 去掉 F、B，**没有半音**，听感更平稳 |
| 蓝调/摇滚 | 偏爱半音（"别扭"的音程） | 制造张力与情绪 |

### 3.5 第三步：十二平均律

自然律在不同调之间转调时会出现音不准的问题。解决办法：把一个八度按**乘法（等比）**均匀切成 12 份。

相邻两个音的频率比恒为：

```
r = 12√2 = 2^(1/12) ≈ 1.059463
```

于是：

- 1 个**半音** = `2^(1/12) ≈ 1.059463`
- 1 个**全音** = `2^(2/12) ≈ 1.122462`（与自然律的 1.125 高度吻合）

::: success 十二平均律的两大红利
1. **兼容一切调式**：无论哪种调式需要几个音，都能从这 12 个音里挑出来。钢琴任意相邻键、吉他任意相邻品之间的频率比都是 `2^(1/12)`。
2. **移调免费**：把所有音符整体平移 k 个半音，就实现整曲升/降 k 个半音，音程关系完全不变。
:::

### 3.6 音程的度数命名

以基准音（如 100 Hz）为 do，按十二平均律数到高八度，共 12 个音，对应 12 个音程名称：

| 半音数 | 音程名称 |
| :--- | :--- |
| 0 | 纯一度（同度） |
| 1 | **小二度** = 半音 |
| 2 | **大二度** = 全音 |
| 3 | 小三度 |
| 4 | 大三度 |
| 5 | 纯四度 |
| 6 | 增四度 / 减五度 |
| 7 | **纯五度**（最和谐的音程之一） |
| 8 | 小六度 |
| 9 | 大六度 |
| 10 | 小七度 |
| 11 | 大七度 |
| 12 | **纯八度**（频率 ×2） |

## 四、音名、唱名与标准音高

### 4.1 国际标准音高

理论上调式可以从任意频率开始，但为了协作，国际上规定：

- **中音 A = 440 Hz**（标准音高 pitch standard）。
- 由此推算，**中音 C ≈ 261.626 Hz**。

::: note 修正前面的假设
前文为直观把 C 取作 100 Hz，实际按国际标准，中音 C 是固定值 261.626 Hz，不是这个值就不能叫"中音 C"。
:::

### 4.2 音名 vs 唱名

| 项目 | 音名 | 唱名 |
| :--- | :--- | :--- |
| 符号 | C D E F G A B | do re mi fa sol la si |
| 频率 | **固定**（由 440 Hz 标准锁定） | 本身无物理意义，是一首圣诗每行首音节 |
| 对应乐器位置 | 与琴键/品格一一对应 | 分固定与首调两种体系 |

### 4.3 两种唱名法

| 唱名法 | 规则 | 优点 | 适用 |
| :--- | :--- | :--- | :--- |
| **固定唱名法** | 唱名与音名一一对应，C 永远唱 do | 见谱即知乐器按键位置 | 中国最常用，配合五线谱 |
| **首调唱名法** | 哪个音是大调起点，哪个音就唱 do | 全全半全全全半的结构感清晰 | 配合简谱、流行音乐 |

举例：

- C 大调（全全半…从 C 起）：C 唱 do。
- D 大调（全全半…从 D 起）：把 C 大调整体右移两个半音到 D，此时 **D 唱 do**。

## 五、乐谱与视唱练耳

### 5.1 乐谱要记录的全部信息

一首乐曲的全部信息只有 4 个参数：

1. **音符**（音高 / 音程关系）——这是最难的一块；
2. 每个音符的**时间长度**；
3. 每个音符的**力度**（重弹/轻弹）；
4. 每个音符的**音色**（用什么乐器）。

后三项凭直觉就能理解，难点全在第 1 项。

### 5.2 为什么"会唱"却"写不出"

生活经验：喜欢一首歌，听几次就能跟着哼出来——说明音高和音程已经进了脑子；但让你把音符写下来，往往写不出。这就像凭感觉知道桌子比椅子高，却报不出具体尺寸。

::: tip 乐谱就是音高的"尺子"
平时随身带把尺子量家具，久而久之看一眼就知道尺寸。学视唱练耳同理：**乐谱就是那把尺子**，靠反复对照把音程量化成本能。
:::

### 5.3 视唱练耳五步训练法

按顺序跟着自己喜欢的歌练：

1. 挑一首喜欢的歌，先学会唱；
2. 找来这首歌的简谱；
3. 边听原曲边看简谱上的音符变化，用"啦——"跟着唱；
4. 边听原曲边看简谱，**用唱名**唱；
5. 关掉原曲，开节拍器，看着简谱用唱名唱。

把喜欢的歌都过一遍，音符就会像母语一样沉淀为本能。

::: warning 不建议一上来就练"绝对音感"
这相当于刚学语文就背整本字典。写作靠的是字与字、句与句的搭配；背完字典依然不会写文章，单个字还会越看越陌生。**先练相对音高（音程感），再谈绝对音高。**
:::

## 六、乐器入门建议

- **推荐工具**：苹果系统自带的**库乐队（GarageBand）**。
- 内置专业且简洁的**钢琴课程**与**吉他课程**，可直接用来入门。
- 钢琴、吉他均基于十二平均律设计：钢琴相邻键频率比 = `2^(1/12)`，吉他相邻品频率比 = `2^(1/12)`。

## 七、专业名词释义

| 名词 | 英文 | 释义 |
| :--- | :--- | :--- |
| 频率 | Frequency | 每秒声波振动的次数，单位赫兹（Hz），决定音高。 |
| 振幅 | Amplitude | 振动的幅度，对应声压与声功率，决定音量（响度）。 |
| 分贝 | dB | 音量的对数比值单位，必须相对某个基准才有意义，不能单独说"某声音是多少 dB"。 |
| 音高 | Pitch | 人耳对频率高低的主观感知，频率主导音高。 |
| 音量 | Loudness | 人耳对声强的主观感知，振幅主导音量。 |
| 纯音 | Pure Tone | 只有单一频率的声音，自然界不存在，仅实验室可生成。 |
| 噪音 | Noise | 多个频率叠加、能量杂乱、无主导频率，听感无固定音高。 |
| 乐音 | Musical Tone | 拥有整齐频率序列的声音，兼具清晰音高与音色。 |
| 基音 / 基频 | Fundamental | 乐音频率序列中最低、能量最强的那个频率，决定音高感知。 |
| 泛音 / 谐音 | Harmonic / Overtone | 基频整数倍的一系列高频成分，能量随频率升高而减弱，决定音色。 |
| 泛音列 | Harmonic Series | 由基频 f 与其整数倍 2f, 3f, 4f… 构成的频率序列。 |
| 音色 | Timbre | 由泛音列中各频率的能量比例决定的声音"质感"，用于区分乐器。 |
| 共振 / 共鸣 | Resonance | 两个音的泛音在某一频率重合时，该频率被相互强化的现象，是"好听/和谐"的物理来源。 |
| 音程 | Interval | 两个音之间的"距离"，人耳按频率比（等比）而非频率差（等差）感知。 |
| 全音 | Whole Tone | 自然律下频率比约 9:8 ≈ 1.125 的音程；十二平均律下为 `2^(2/12) ≈ 1.122462`。 |
| 半音 | Semitone | 最小音程单位，十二平均律下频率比恒为 `2^(1/12) ≈ 1.059463`。 |
| 八度 | Octave | 频率比为 2 的音程，记为纯八度；高八度音 = 低八度同音名 ×2。 |
| 自然大调式音阶 | Major Scale | 由"全全半全全全半"音程关系构成的七声音阶。 |
| 调式 | Mode / Key | 在一个八度内选择哪些音、规定相邻音程关系的体系（大调、五声调式、蓝调等）。 |
| 五声调式 | Pentatonic Scale | 中国古代宫商角徵羽体系，相当于大调去掉 F、B，无半音。 |
| 十二平均律 | 12-TET | 将一个八度按等比关系均分 12 份、相邻音频率比恒为 `12√2` 的律制。 |
| 移调 | Transposition | 把整首乐曲所有音符整体平移若干半音，保持音程关系不变。 |
| 音名 | Pitch Name | C D E F G A B，与固定频率一一对应（由标准音锁定）。 |
| 唱名 | Solfège | do re mi fa sol la si，为方便视唱而起的音节名称，分固定/首调两种用法。 |
| 固定唱名法 | Fixed Do | 唱名与音名一一对应、永久不变的唱名体系。 |
| 首调唱名法 | Movable Do | 大调起点音永远唱 do，调升高后 do 随之移到新的主音。 |
| 标准音高 | A440 | 国际规定中音 A = 440 Hz，由此锁定全部音名频率。 |
| 中音 C | Middle C | 按 A440 推出约为 261.626 Hz 的中央 C。 |
| 和弦 | Chord | 同时弹奏至少三个不同音高的音符形成的组合，靠泛音重叠共振获得丰满感。 |
| 简谱 | Numbered Notation | 用数字 1–7 记录唱名、便于视唱的记谱方式，与首调唱名法配合紧密。 |
| 视唱练耳 | Sight-singing & Ear Training | "看谱即唱"与"听声记谱"能力的合称，需通过对照乐谱反复训练。 |
| 绝对音感 | Absolute Pitch | 不依赖参照音即可说出任意音高的能力；建议先练相对音高（音程感）。 |
