# 从持续学习到 AGI：梁文锋的六阶梯论与研究前沿系统综述

2026 年 7 月，DeepSeek 创始人梁文锋在一场长达四小时的投资人闭门会议中系统阐述了其 AGI 路线图，提出"**语言模型 → 思维链 → Agent → 持续学习 → 自我迭代 → 具身智能**"的六阶梯递进结构，并明确指出**持续学习是 Agent 之后通往 AGI 最关键的一步**。本文围绕这一判断，从三个层面展开分析：六阶梯论的内在逻辑及持续学习的战略定位；全球高校在持续学习领域的研究方向与流派（经典方法 + 面向大模型时代的新范式）；学术界与产业界的路径预测与 AGI 距离评估。

## 一、梁文锋的六阶梯论：持续学习为何是 AGI 的关键跳板

### 1. 六阶梯的递进逻辑

梁文锋将 AGI 的实现路径比作"爬楼梯"，认为每一步都不能跳步。六阶梯的递进关系如下表所示：

| 阶梯 | 环节 | 核心能力 |
| :--- | :--- | :--- |
| 1 | 语言模型 | 基础理解与生成 |
| 2 | 思维链（CoT） | 推理能力 |
| 3 | Agent | 自主执行任务 |
| 4 | 持续学习 ★ | 从经验中持续改进 |
| 5 | 自我迭代·奇点 | AI 加速 AI 研究 |
| 6 | 具身智能 | 走进现实世界 |

"去年的阶梯是 CoT，今年的阶梯就是 Agent。**在 Agent 之后要解决的问题就是持续学习**。"梁文锋判断，AI 当前不缺品位和直觉，缺的是持续学习的能力——"下一代模型必须要有持续学习的能力，才能叫下一代模型"。

这一判断的核心逻辑在于：语言模型提供基础的理解和生成能力；思维链让模型具备推理能力；Agent 让模型能在更大范围内自主执行任务——"用 Agent 的方式，即便多些事情也可以做，它的能力范围会更大，它的智能上限会更高"。但 **Agent 仍然是静态的**，部署之后无法从经验中持续改进。梁文锋用一个直白的类比解释：

::: tip 原话摘录
"AI 并不能够替代你的员工。但如果说 AI 具有持续学习的能力，它跟你的员工一样，到公司学习两个月，那么就可以替代天下的人了，所以我们离下一步还差一个持续学习。"
:::

### 2. 持续学习之后：渐进奇点

在梁文锋的路线图中，持续学习之后将迎来一个"**渐进的奇点**"——模型可以完成人类能做的所有事情，包括自己开发更前沿的模型（AI 加速 AI 研究）。走完这一步，才是具身智能："到具身智能之后，它就走进现实世界，可以给你做家务，可以给你养老。"

值得注意的是，梁文锋明确将**世界模型排除在 AGI 主线之外**："世界模型和智能还不是现在这个阶段最重要的事情。最重要的才是 AI 训练，以及 AI 训练之后怎么解决持续学习。"这一判断与他对视频生成、3D 建模等热门赛道的战略放弃一脉相承——**DeepSeek 只做 AGI 主线，不为"好商业"做支线**。

### 3. 与学术界判断的呼应

梁文锋的判断并非孤立：

- **Google DeepMind CEO** 同样将持续学习列为 AGI 实现前必须解决的三大核心问题之一（另外两个是记忆和推理）。
- **DeepMind 创始人 Shane Legg** 表示："AGI 一路坦途，最新进展就是嵌套学习。"
- **Andrej Karpathy** 指出，当前模型"没有持续学习能力，你不能只是告诉它们一些事情，然后它们就会记住"，并将其描述为"认知上的缺失"。
- 一篇 2026 年 8 月发表的综述论文给出审慎判断：记忆和工程层面的"记忆-外围"路线正在快速接近通用助手的能力上限，但真正的 AGI——能自主扩展能力、跨领域迁移、稳健进行长程决策的系统——距离仍然相当遥远。该论文同时指出，"**持续学习的缺失是当前系统通往 AGI 道路上的首要瓶颈**，因为提示工程和长滚动上下文是脆弱的补丁，无法泛化到以文本为中心的领域之外"。

## 二、持续学习的高校研究方向与流派

持续学习（Continual Learning，也称终身学习 Lifelong Learning 或增量学习 Incremental Learning）在学术界已有二十余年研究历史，但大语言模型和 Agent 系统的出现正在从根本上重塑这一领域的研究版图。一篇 2026 年综述提出了**三维分析框架**：**When**（学习发生在预训练、后训练还是推理阶段）、**How**（学习机制是离策略、在策略还是超越梯度的优化）、**Where**（更新发生在模型内部参数还是外部结构约束中），并指出这些发展共同标志着持续学习"**从以参数为中心的学习转向系统级的适应**"。

持续学习研究版图可按两条主线划分：

| 主线 | 分支 | 代表思想 |
| :--- | :--- | :--- |
| 经典流派（以参数为中心） | 基于回放 | 训练新任务时重放旧任务样本 |
| | 基于正则化 | 惩罚对重要参数的剧烈改变（如 EWC） |
| | 参数隔离与架构扩展 | 为每个新任务增加新节点/层，冻结旧参数 |
| | 混合方法 | 组合上述多种策略 |
| 大模型时代新范式 | PEFT 驱动（LoRA 系列） | 仅更新低秩增量矩阵 |
| | 测试时训练 | 将学习延伸到推理阶段 |
| | 元学习交叉 | "学会学习"的快速适应 |
| | 神经符号结合 | 神经网络 + 符号推理协同 |
| | 记忆增强与 Agent 式 | 靠外部记忆系统持续适应 |
| | 联邦持续学习 | 分布式非平稳数据上的终身自适应 |

### 1. 经典流派：以参数为中心的持续学习

传统深度学习框架下，持续学习的核心挑战是**灾难性遗忘**——模型在学习新任务时严重退化在旧任务上的性能。围绕这一问题形成四大经典流派：

| 流派 | 核心机制 | 优点 | 局限 |
| :--- | :--- | :--- | :--- |
| **基于回放** | 训练新任务时重放旧任务样本 | 简洁有效、广泛采用 | 依赖存储样本质量；隐私敏感场景存储旧数据本身即挑战 |
| **基于正则化** | 目标函数引入正则项，惩罚对重要参数的剧烈改变（如 EWC） | 无需存储旧数据 | 任务差异较大时效果受限 |
| **参数隔离与架构扩展** | 为每个新任务增加新节点/层，冻结旧参数 | 不干扰旧知识 | 随任务数增长，计算与存储需求增大 |
| **混合方法** | 组合上述多种策略 | 取长补短 | 复杂度上升 |

**示例**：一项发表于 Scientific Reports 的研究首次系统地将**神经常微分方程与记忆增强 Transformer** 结合——通过连续时间动力学实现平滑表征学习，同时利用注意力机制进行知识巩固，在 Split CIFAR-100 等基准上实现了 **24% 的遗忘减少和 10.3% 的准确率提升**。

**正则化流派的代表公式**（弹性权重巩固，EWC）：通过在损失中惩罚重要参数的变化来缓解遗忘，其目标函数可写成：

```text
L(θ) = L_B(θ) + Σ_i (λ/2) · F_i · (θ_i − θ*_{A,i})²
```

其中 `F_i` 为 Fisher 信息量（衡量参数重要性），`θ*_A` 为旧任务学到的参数。惩罚项使得偏离旧参数越远、代价越大，从而在更新新任务时保护旧知识。

### 2. 面向大模型的新范式

随着大语言模型成为主流架构，持续学习的研究场景和方法论都在发生深刻变化：

| 新范式 | 代表工作 | 核心思想 | 关键成果 |
| :--- | :--- | :--- | :--- |
| **参数高效微调驱动** | SD-LoRA（ICLR 2025 Oral）、Stacked LoRA | 分解低秩矩阵的方向与幅值，固定已学方向、仅调幅值 | SD-LoRA 减少 50%+ 参数存储同时保持最高准确率；Stacked LoRA 在 Llama-3.2-1B 上几乎完全消除灾难性遗忘 |
| **测试时训练** | ARC（ICLR 2025） | 将学习延伸到推理阶段，部署后遇新数据实时适应 | CIFAR-100 与 ImageNet-R 分别提升 2.7% 和 2.6%；模糊"训练期/测试期"界限 |
| **元学习交叉** | CoSFan、Amphibian | "学会学习"：慢适应积累长期知识、快适应快速迁移 | 在快速学习与持续学习间取得平衡 |
| **神经符号结合** | NeSyBiCL、NeSyC | 神经网络快速适应 + 符号推理保持知识 | 双子系统架构；结合 LLM 与符号工具实现具身任务持续学习 |
| **记忆增强与 Agent 式** | Memento、Memento 2 | 不更新模型权重，靠外部记忆系统持续适应 | 基于案例推理 + 反思存储于情节记忆；"无需微调即持续适应" |
| **联邦持续学习** | 新兴交叉方向 | 联邦学习 + 持续学习，分布式非平稳数据上终身自适应 | 支持隐私保护的大规模部署 |

**PEFT 新范式的数学直觉**（LoRA 低秩适配）：冻结预训练权重 `W_0`，仅训练低秩增量：

```text
W = W_0 + ΔW = W_0 + B·A，  B ∈ R^{d×r}， A ∈ R^{r×k}， r ≪ min(d,k)
```

SD-LoRA 进一步将 `A`（或方向/幅值）解耦，只更新幅值部分，从而"无需回放"地保持旧任务知识。

## 三、可能成功的路径预测

### 1. 近期（1–2 年）：测试时训练 + 参数高效微调的组合

最可能率先突破的组合，理由有三：第一，LoRA 系列已展现近乎完全消除灾难性遗忘的能力（Stacked LoRA 在 Llama-3.2-1B 实现 **92.75% 旧任务保持率**），"稳定性-可塑性"困境在 PEFT 范式下已有工程可行的解法；第二，测试时训练将学习延伸到推理阶段，恰好是梁文锋所说"到公司学习两个月"的技术基础；第三，两者结合（测试时通过 LoRA 高效更新实现快速适应）既保持推理效率又实现持续学习，SD-LoRA 的"无需回放"特性尤其适合在线场景。

### 2. 中期（2–3 年）：系统级适应——记忆 + 技能库 + Agent 架构

梁文锋所说的持续学习不仅是模型权重更新，更可能指向**系统级适应框架**（与综述提出的"从参数中心转向系统级适应"高度吻合）：以 LLM 为基座，通过**外部记忆系统**（如 Memento 的反思记忆）积累经验、通过**技能库**存储可复用行为策略、通过**交互协议**实现环境反馈驱动的行为调整。模型权重相对稳定，但系统整体能力持续增长。DeepMind 的 HOPE 嵌套学习、DRAE 的"知识检索与参数更新解耦"思路均为此路径提供参考。

### 3. 远期（3–5 年）：神经符号融合驱动的自主能力扩展

真正的 AGI 需要的不仅是"不忘"，更是"**自主扩展**"——自主定义新问题、设计学习策略、验证学习结果。这需要符号推理系统提供逻辑框架和验证机制，神经网络提供感知与模式识别，两者协同实现持续的知识积累。NeSyC 等工作已在具身任务的开放域中验证了这一范式的可行性。

### 4. 与梁文锋"渐进奇点"的对照

梁文锋的"渐进奇点"本质上要求持续学习系统具备**元学习能力和自我改进闭环**。ALLA 架构提出的"自学者循环"提供了理论蓝图：在"意识工作空间"中用语言强化学习解决新问题 → 通过"智慧过滤器"识别可推广策略 → 通过"蒸馏引擎"固化为 LoRA 适配器，成为永久高速能力，从而在无灾难性遗忘的情况下持续学习新技能。

这一蓝图与梁文锋的判断形成对照：梁文锋强调"到公司学习两个月"式的经验积累；ALLA 强调"语言自我修正的可解释性"与"模块化权重更新的效率"结合。两者共同指向的核心洞察：**持续学习不是单一技术的突破，而是记忆、反思、固化和验证多个环节的系统工程**。

## 四、结论

梁文锋将持续学习定位为 Agent 之后、奇点之前的关键阶梯，这一判断与全球学术界和产业界的前沿趋势高度一致。当前持续学习的研究正经历从"以参数为中心"向"系统级适应"的深刻转型，测试时训练、参数高效微调、元学习、神经符号融合和记忆增强 Agent 等新范式正在快速重塑方法论版图。

从可能成功的路径看：**近期**最值得关注测试时训练与参数高效微调的组合（已展现近乎消除灾难性遗忘的能力，工程可行）；**中期**可能走向以外部记忆和技能库为核心的系统级适应架构；**远期**需要神经符号融合支撑真正的自主能力扩展。

DeepMind 预测 2026 年将成为"持续学习之年"，但审慎地看：记忆和工程层面的持续学习正快速接近通用助手的能力上限，而真正的 AGI——能自主扩展能力、跨领域迁移、稳健进行长程决策的系统——距离仍然相当遥远。梁文锋的"渐进奇点"或许终将到来，但它更可能是一个渐进的过程，而非某个确定日期的突然降临。
