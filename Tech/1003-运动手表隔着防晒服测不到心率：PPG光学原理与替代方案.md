# 运动手表隔着防晒服测不到心率：PPG 光学原理与替代方案

运动手表套在防晒服上测不了心率，核心原因是：**它测心率靠的是"光"，而不是"电"或"压力"，而防晒服挡住了光，也隔开了皮肤。**

> 核心命题：PPG 光学心率必须满足两个条件——光能照进皮肤、反射光能被传感器收到。任何阻断光路的遮挡物（织物、污渍、间隙）都会让算法判定"无有效信号"。理解这一点，就能解释隔衣测不准的全部现象，并推导出正确的替代方案。

---

### 一、PPG 技术原理

现在大多数运动手表用的是 **光电容积脉搏波（PPG）** 技术，原理分三步：

1. **发射**：手表背面的绿光（或红光/红外光）射进皮肤；
2. **调制**：血液在血管里随心跳一涨一缩，对光的吸收量周期性变化；
3. **接收**：手表背面的光敏传感器接收反射回来的光，根据这个变化算出心率。

```text
PPG 信号链路：
LED 发光 ─→ 皮肤/血管吸收（随心跳周期性变化） ─→ 反射光 ─→ 光敏传感器 ─→ 算法解算心率
        └────────────── 必须直达皮肤，不得有遮挡 ──────────────┘
```

所以它必须满足两个条件：**光能照进皮肤，反射光能被传感器收到。**

---

### 二、为什么隔着防晒服测不了

| # | 原因 | 机制 |
| :--- | :--- | :--- |
| 1 | **光被挡住** | 防晒服通常不透光或透光很差，绿光照不到皮肤，传感器收不到反射光 |
| 2 | **没有血液信号** | 即使有少量光透过，反射回来的主要是衣服纤维的反射，不是血液脉动信号，算法判定"无有效信号" |
| 3 | **贴合压力不对** | 隔着一层布，压力分布改变，传感器与皮肤之间存在空气/织物间隙，信号更弱 |
| 4 | **摩擦和位移** | 运动时衣服与手表之间滑动，传感器位置不稳定，导致读数失败或乱跳 |

简单说：**手表需要"看见"你皮肤下的血流，防晒服把它眼睛蒙住了。**

---

### 三、可行的替代方案

| 方案 | 原理 | 适用场景 |
| :--- | :--- | :--- |
| **拉高袖口** | 让手表直接贴皮肤 | 袖口宽松可上拉的防晒服 |
| **选开孔/外戴设计** | 袖口有开孔或手表外戴位 | 专门为手表设计的运动防晒服 |
| **心率带（胸带/臂带）** | 测心电信号，不受衣服遮挡影响，隔着薄衣服也能用 | 需要连续准确心率的运动 |
| **外接心率设备** | 手表连接外部心率带，用外接设备的数据 | 手表支持 ANT+/蓝牙连接时 |

```text
选型决策：
运动时需要心率且穿防晒服？
├─ 短途/休闲 → 拉高袖口或选开孔袖口
├─ 高强度/需准确心率 → 心率带（胸带/臂带）
└─ 已有运动手表 → 确认是否支持连接外部心率带
```

### 四、专业名词释义

| 术语 | 英文 | 核心概念 | 来源/背景 | 解决什么问题 |
| :--- | :--- | :--- | :--- | :--- |
| **光电容积脉搏波** | Photoplethysmography (PPG) | 利用光吸收变化测量血容积脉动的技术 | 生物医学工程 | 无创光学心率测量 |
| **光敏传感器** | Photosensor / Photodetector | 将光信号转换为电信号的器件 | 传感器技术 | 接收反射光 |
| **反射光** | Reflected Light | 经皮肤与组织反射回传感器的光 | 光学测量 | 携带血液脉动信息 |
| **心电信号** | Electrocardiogram (ECG) | 心脏电活动产生的生物电信号 | 生理学 | 高精度心率测量 |
| **心率带** | Heart Rate Strap | 通过电极采集心电信号的胸带/臂带 | 运动装备 | 抗遮挡、高精度测心率 |
| **信噪比** | Signal-to-Noise Ratio (SNR) | 有效信号与噪声的比值 | 信号处理 | 衡量读数可靠性 |
| **贴合压力** | Contact Pressure | 传感器与皮肤间的接触压力 | 可穿戴设备设计 | 保证光路稳定 |
| **ANT+ / 蓝牙** | ANT+ / Bluetooth | 运动设备无线通信协议 | 无线通信 | 连接外部心率设备 |
