# Anki 完全入门指南：从理念到实践

::: tip 本文说明
本文面向首次接触 Anki 的新手，也适合希望系统理解其原理的老用户。内容分为原理、功能、价值、教程与常见问题五部分，可按需阅读。
:::

## 一、Anki 是什么

Anki 是一款免费开源的抽认卡（Flashcard）程序。其名称源自日语“暗記”（Anki），意为“记忆”。它并非简单的电子卡片工具，而是一套基于认知科学原理设计的记忆管理系统。

与传统纸质卡片或普通背单词软件不同，Anki 的核心价值在于：**它不是帮你“背”东西，而是帮你“不忘”东西**。通过科学的算法，Anki 会在你即将遗忘某个知识点的最佳时机提醒你复习，从而实现以最小的时间投入获得最牢固的记忆保留。

Anki 自 2006 年首次发布以来，经过近二十年的发展，已成为全球最成熟、最强大的间隔重复学习系统。

## 二、Anki 的核心理念

Anki 背后有两个简单而深刻的理念：

### 2.1 主动召回测试（Active Recall Testing）

主动召回测试是指**被问到一个问题并尝试回忆答案**的过程。这与被动学习——如单纯阅读、观看或听讲而不主动思考——形成鲜明对比。

研究表明，主动召回测试在建立牢固记忆方面远比被动学习有效。原因有二：

1. **回忆行为本身强化记忆**：每一次主动提取信息，都会加强神经通路，增加未来再次回忆成功的概率。
2. **失败揭示知识缺口**：当我们无法回答一个问题时，便明确知道自己需要返回材料重新学习。

Anki 的卡片设计天然遵循这一原则：**正面是问题，背面是答案**。你先思考、再核对，这种“费力”的提取过程正是记忆强化的关键。相比之下，被动阅读的效率仅为主动召回的三分之一左右。

### 2.2 间隔重复（Spaced Repetition）

间隔重复的原理可以追溯到 1885 年德国心理学家赫尔曼·艾宾浩斯的研究。艾宾浩斯发现，人类会在**24 小时内遗忘约 70% 的新信息**——除非按照科学优化的时间间隔进行复习。

记忆的遗忘速率遵循“先快后慢”的规律：刚学完后遗忘最快，而每一次成功复习都会减缓遗忘速度。Anki 的算法正是基于这一规律：

- 你学完一个知识点后，Anki 会在你**即将遗忘之前**提醒你复习。
- 如果你成功回忆，下一次复习的间隔会**逐步延长**（例如：1 天 → 3 天 → 1 周 → 1 个月……）。
- 这种“在正确的时间做正确的事”的策略，避免了过早复习（浪费时间）和过晚复习（需要重新学习）。

### 2.3 两大理念的协同效应

主动召回测试与间隔重复的结合产生了 1+1>2 的效果。Anki 通过科学的复习算法加上强制性的主动召回，**将你的大脑从“何时复习什么”的决策负担中解放出来**，让你能够专注于理解和推理本身。

## 三、Anki 的核心功能

### 3.1 卡片系统（Cards）

Anki 中最基本的单位是卡片——一个**问答对**。一张卡片包含正面（问题）和背面（答案），类似于纸质抽认卡。

Anki 支持多种卡片类型：

| 卡片类型 | 说明 | 适用场景 |
|---------|------|---------|
| **基础型** | 标准问答模式，正面问题、背面答案 | 术语记忆、公式背诵 |
| **填空型（Cloze）** | 在文本中挖空，隐藏关键词 | 概念记忆、句子填空 |
| **逆向型** | 自动生成双向问答（正→反、反→正） | 双向关联知识（如中英互译） |
| **图像遮挡（Image Occlusion）** | 在图片上遮挡特定区域 | 解剖学、地图、图表等空间知识 |

### 3.2 牌组系统（Decks）

牌组是卡片的**分组容器**。你可以将不同学科的卡片放入不同牌组，避免混杂学习。

牌组支持**层级嵌套**，使用双冒号“::”表示层级关系。例如，“中文::汉字”表示“汉字”牌组是“中文”牌组的子牌组。每个牌组可以独立设置学习参数，如每日新卡数量、复习间隔等。

### 3.3 卡片状态（Card States）

每张卡片在学习过程中会经历不同的状态：

- **新卡（New）**：已创建但从未学习过的卡片。
- **学习中（Learning）**：首次学习后尚未掌握，仍在短期记忆阶段。
- **复习卡（Review）**：已完成学习阶段，按间隔进行周期性复习。
  - **年轻卡（Young）**：间隔少于 21 天。
  - **成熟卡（Mature）**：间隔达到或超过 21 天。
- **重学中（Relearn）**：复习时遗忘的卡片，回到学习状态。

### 3.4 复习算法

Anki 默认使用 **SM-2 算法**（SuperMemo 2），这是间隔重复领域最经典的算法之一。回答时，你需要在四个选项中选择：

| 选项 | 含义 | 对间隔的影响 |
|------|------|------------|
| **Again（再次）** | 完全忘记 | 重置间隔，重新学习 |
| **Hard（困难）** | 勉强回忆 | 略微缩短下次间隔 |
| **Good（良好）** | 成功回忆 | 按正常比例延长间隔（约 1.5-2.5 倍） |
| **Easy（简单）** | 轻松回忆 | 大幅延长间隔 |

### 3.5 FSRS 算法（新一代调度器）

Anki 现已支持 **FSRS（Free Spaced Repetition Scheduler）**，这是一款基于机器学习的新一代调度算法。

FSRS 的核心优势在于：

- **个性化**：基于你个人的复习历史数据，计算出最适合你的遗忘曲线。
- **效率更高**：相比 SM-2，FSRS 可减少 **20-30% 的复习次数**。
- **三维度建模**：将记忆量化为三个参数——**难度（Difficulty）**、**稳定性（Stability）**和**可提取性（Retrievability）**，精准预测每张卡片的遗忘时间。

FSRS 已内置于 Anki 较新版本中，可在牌组设置中直接启用。

## 四、Anki 的应用价值

### 4.1 科学验证的高效性

Anki 基于认知科学中已被充分验证的原理。研究表明，使用间隔重复方法可将知识留存率提升至 **90% 以上**。在相同的学习时间内，Anki 用户能够掌握远超传统学习法的知识量。

### 4.2 内容无关性（Content-Agnostic）

Anki 不限定任何学科或内容类型。你可以用它来记忆：

- 外语单词和语法
- 医学、法律等专业考试内容
- 编程概念和代码片段
- 人名和面孔
- 地理知识
- 长诗
- 甚至吉他和弦

任何需要记忆的内容，都可以用 Anki 来管理。

### 4.3 强大的多媒体支持

Anki 卡片支持嵌入**图片、音频、视频和科学标记（LaTeX 数学公式）**。这使得它特别适合需要视觉或听觉辅助的学习场景，如解剖学图片标记、语言发音练习、数学公式展示等。

### 4.4 海量数据处理能力

Anki 可以**轻松处理 10 万张以上的卡片**而不会出现性能问题。这意味着它适用于长期、大规模的知识积累项目，而不仅是短期备考。

### 4.5 跨设备同步

通过免费的 **AnkiWeb 同步服务**，你可以在电脑、手机、平板之间无缝同步学习进度。无论何时何地，打开任何设备都能继续学习。

### 4.6 开源与插件生态

Anki 是**开源软件**，拥有超过 **3000 个插件**。这些插件可以极大地扩展 Anki 的功能：

- 图片遮挡增强（Image Occlusion Enhanced）
- 学习热力图（Heatmap）——可视化你的学习规律
- 文本转语音（AwesomeTTS）
- AI 辅助卡片生成
- 协作平台集成（AnkiCollab）

### 4.7 与同类工具的对比

| 维度 | Anki | Quizlet |
|------|------|---------|
| **核心理念** | 间隔重复 + 主动召回 | 快速刷题与游戏化学习 |
| **算法复杂度** | SM-2 / FSRS 高级调度 | 基础间隔安排 |
| **长期记忆效果** | 极佳（专为长期设计） | 一般（更适合短期备考） |
| **自定义能力** | 极高（开源 + 插件） | 有限 |
| **上手难度** | 较高 | 极低 |
| **价格** | 桌面版/安卓免费，iOS 付费 | 订阅制 |
| **适合人群** | 严肃学习者、长期记忆需求 | K12 学生、临时备考 |

## 五、适用人群

Anki 最适合以下人群：

### 5.1 医学生

医学院学生需要记忆海量的解剖学、药理学、病理学知识。Anki 的图像遮挡功能特别适合解剖结构记忆。全球大量医学生使用 Anki 备考 USMLE 等执业医师考试。

### 5.2 语言学习者

从背单词到记忆语法规则、例句，Anki 可以成为语言学习的核心工具。配合音频和 TTS 插件，可以实现听说读写的全面训练。

### 5.3 法学生

法律学习涉及大量案例、法条和原则的记忆。Anki 的间隔重复系统可以帮助法学生在长时间跨度内保持对大量法律知识的精确记忆。

### 5.4 程序员与工程师

编程涉及大量语法、API、算法和设计模式的记忆。Anki 支持代码片段和 LaTeX 公式，适合技术知识的长期积累。

### 5.5 各类考试备考者

从高考、考研到各类职业资格证考试，任何需要大量记忆的备考场景都适合使用 Anki。

### 5.6 知识工作者

任何需要长期积累和保持专业知识的从业者——教师、研究员、翻译、咨询师等——都可以从 Anki 中获益。

::: warning 注意
Anki 不适合追求“开箱即用”的 casual learner。它需要一定的学习曲线和持续的投入，回报在于长期的高效记忆。
:::

## 六、新手完整教程

### 6.1 第一步：安装 Anki

Anki 生态包含四个组成部分：

| 平台 | 名称 | 说明 |
|------|------|------|
| Windows / macOS / Linux | Anki（桌面版） | 免费，功能最完整 |
| Android | AnkiDroid | 免费，由社区开发维护 |
| iOS | AnkiMobile Flashcards | 付费（约 163 元），官方 iOS 应用 |
| 网页 | AnkiWeb | 免费同步与在线学习服务 |

**下载方式**：

- 桌面版：访问 [https://apps.ankiweb.net](https://apps.ankiweb.net) 下载对应系统版本。
- 安卓：在应用商店搜索“AnkiDroid”。
- iOS：在 App Store 搜索“AnkiMobile Flashcards”。

### 6.2 第二步：注册 AnkiWeb 账号（用于同步）

在多设备间同步学习进度，需要注册 AnkiWeb 账号：

1. 访问 [http://ankiweb.net/account/register](http://ankiweb.net/account/register)。
2. 用邮箱注册免费账号。
3. 在 Anki 客户端中点击同步按钮，输入账号密码即可。

### 6.3 第三步：创建牌组

启动 Anki 后：

1. 点击主界面的 **“创建牌组”（Create Deck）**。
2. 输入牌组名称（如“考研英语词汇”或“Python 基础”）。
3. 点击确定完成创建。

建议按**学科或主题**创建不同的牌组，避免所有卡片混在一起。

### 6.4 第四步：添加卡片

点击主界面顶部的 **“添加”（Add）** 按钮或按快捷键 **A**：

1. 在 **“类型”（Type）** 中选择卡片类型（默认“基础”即可）。
2. 在 **“牌组”（Deck）** 中选择目标牌组。
3. 在 **“正面”（Front）** 字段输入问题。
4. 在 **“背面”（Back）** 字段输入答案。
5. 点击 **“添加”（Add）** 保存卡片。

### 6.5 第五步：开始学习

1. 在主界面**点击牌组名称**。
2. 点击 **“开始学习”（Study Now）**。
3. 查看正面问题，**先努力回忆答案**。
4. 点击 **“显示答案”（Show Answer）**。
5. 根据回忆情况选择 **Again / Hard / Good / Easy**。

### 6.6 第六步：导入预制牌组

Anki 拥有庞大的社区共享牌组库，涵盖从语言到医学的各种主题。导入方式：

- **PC 端**：菜单栏“文件”→“导入”，或直接双击 `.apkg` 文件。
- **安卓端**：在主界面右上角三个点处选择“导入牌组”。
- **iOS 端**：下载牌组文件后，选择“用 Anki 打开”。

### 6.7 第七步：多设备同步

在任意设备上完成学习后，点击**同步按钮**（通常是旋转箭头图标），即可将进度同步到所有设备。

## 七、新手核心技巧

### 7.1 最小信息原则（Minimum Information Principle）

**每张卡片只包含一个最小概念**。例如：

- ❌ 错误：“请解释 TCP 三次握手和四次挥手”。
- ✅ 正确：
  - “第一次握手的目的是什么？”
  - “为什么需要第三次握手？”
  - “TIME_WAIT 的作用是什么？”

拆分后的卡片更易记忆，也便于算法精准调度。

### 7.2 诚实自评

复习时**诚实地**选择 Again/Hard/Good/Easy。如果只是“感觉知道”但说不出来，应选择 Again 或 Hard。自我欺骗只会降低系统效率。

### 7.3 坚持每日使用

间隔重复的力量在于**一致性**。每天投入 **15-30 分钟**进行复习。中断会导致卡片积压，打乱算法的调度节奏。

### 7.4 先理解，后记忆

Anki 辅助记忆，但**不代替理解**。在制作卡片之前，确保你已经真正理解了知识点的原理和逻辑。只有理解的知识才值得被长期记忆。

### 7.5 持续迭代

你的牌组是**不断演化的**。随着理解加深，随时修订、拆分或优化卡片。低质量的卡片不仅浪费复习时间，还可能造成误解。

## 八、常见问题

### Q1：Anki 是免费的吗？

桌面版和安卓版完全免费。iOS 版 AnkiMobile 是付费应用，费用用于支持 Anki 的持续开发。

### Q2：Anki 和普通背单词软件有什么区别？

普通背单词软件通常采用固定的复习计划（如艾宾浩斯曲线），而 Anki 根据**你个人的表现**动态调整每张卡片的复习时间，实现真正的个性化。

### Q3：每天应该学多少张新卡？

建议从 **每天 10-20 张新卡**开始。随着复习量的增加，根据个人时间调整。关键是保持可持续性，不要贪多导致无法坚持。

### Q4：如何避免卡片堆积？

- 合理设定每日新卡上限。
- 坚持每日完成当天的复习任务。
- 如果堆积严重，可暂时降低新卡数量，优先处理复习卡。

### Q5：Anki 支持中文吗？

支持。Anki 桌面版支持包括简体中文、繁体中文在内的 52 种语言。
