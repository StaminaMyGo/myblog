# 飞书妙记详解

## 产品概述

### 什么是妙记

飞书妙记（简称“妙记”）是字节跳动旗下飞书内置的音视频转文字效率工具。它依托字节跳动的 AI 语音识别技术，在会议、培训、访谈、课堂等场景中，将音视频内容转录为可搜索、重点高亮、互动多样的智能文字笔记。

妙记并非独立的 App，而是存在于飞书客户端及飞书网页端的功能模块。它于 2020 年 11 月随飞书全新版本发布，定位为将会议信息转化为知识的智能文字笔记。

### 产品定位与价值

妙记主要解决传统会议记录场景中的痛点：

| 痛点 | 妙记解决方案 |
|------|-------------|
| 会议记录效率低下 | AI 自动转写，无需专人手动记录 |
| 信息检索困难 | 全文搜索，点击即可定位到对应音视频位置 |
| 内容分享不便 | 一键分享链接，包含完整上下文 |
| 多语言沟通障碍 | 19 种语言互译，降低语言隔阂 |

妙记的定位是将零散的语音信息转化为可搜索、可协作、可复用的结构化知识资产。

## 核心功能

### 高精度语音转写

依托字节跳动自研的语音识别（ASR）技术，妙记提供语音转文字能力：

- 中文普通话转写准确率约 98%。
- 带口音的中文、英文等主流语言准确率约 95% 以上。
- 转写速度约 1:0.1（10 分钟音频约 1 分钟完成转写）。
- 支持中英混说、方言词汇（如粤语、四川话等）的识别。
- 支持中、英、日、韩等 24 种主流语言转写及多种方言识别。
- 支持 19 种语言实时互译。

### 智能说话人识别

- 通过声纹识别技术自动区分不同发言人。
- 每个发言人自动标注，结构清晰。
- 若说话人绑定飞书通讯录，可自动显示姓名。
- 上传的音频文件或通过会议室设备录制的妙记，均会自动识别并拆分说话人。

### 音字同步定位

妙记提供音字同步定位能力：

- 点击文字记录中的任意字词，即可跳转至对应的音视频位置。
- 点击视频画面下方的发言人时间轴，可快速定位到特定发言人的发言内容。
- 点击进度条上的圆点也可进行定位。

### 智能信息提取与整理

- 自动提取会议要点、待办事项与风险预警。
- AI 自动生成结构化摘要、要点提炼与问答回顾。
- 集成 DeepSeek R1 等大模型，强化智能摘要、问答及知识库对接能力。
- 可节省大量人工整理时间。

### 高效协作功能

- 转写稿支持多人实时标注、@同事、评论与任务拆解。
- 支持高亮关键信息。
- 一键导出为飞书文档、TXT、SRT 等格式。
- 支持片段创建与分享，确保分享内容聚焦，降低敏感信息外泄风险。
- 可同步至飞书任务，或同步群聊自动推送纪要。

### 多语言支持

- 支持多种语言的转录和翻译，便于跨国团队协作。
- 外国同事打开链接后可选择母语了解会议内容。
- 支持双语对照显示。

## 技术规格

### 转写链路（技术架构）

妙记的转写链路指从原始音频输入到输出最终文本的完整数据流处理流水线。

整体链路如下：

`原始音频采集 → 音频预处理 → VAD 语音端点检测 → 分块切片 → ASR 语音识别模型推理 → 后处理纠错 → 业务层加工 → 返回转写文本`

各环节说明如下。

**1. 音频采集与输入层**

- 来源：麦克风实时录音，或上传音频文件（mp3、wav、m4a）。
- 统一重采样：强制转为模型输入的标准采样率（一般为 16kHz 单声道）。
- 格式解码：将压缩音频解码为 PCM 原始波形数据。

**2. 音频预处理**

- 降噪：抑制环境背景噪声与设备底噪。
- 增益调节：进行音量归一化，避免声音过小或爆音。

该步骤不做识别，只优化波形质量，用于提升后续 ASR 准确率。

**3. VAD 语音端点检测**

- 核心是区分人声片段与静音片段。
- 切掉长时间静音，不送入识别模型，以节省算力。
- 输出为只包含人声的音频片段。

**4. 音频分块切片**

ASR 模型不能一次性处理超长音频，因此将人声切分为固定时长块（例如 200ms 至 2s）。

- 切片保留重叠窗口，防止一句话被切在中间导致丢字。
- 记录时间戳，为生成字级时间轴做准备。

**5. ASR 模型推理（核心识别）**

- 输入为分块后的 PCM 音频特征（梅尔频谱）。
- 输出为音素 / 字符序列，以及每个字符的时间戳。
- 底层 ASR 支持普通话、中英混杂、方言，并支持说话人分离（diarization）。

**6. 后处理层**

1. 说话人聚类：区分说话人，输出说话人标记。
2. 文本纠错：同音纠错、口语规范化，过滤语气词与重复口头禅。
3. 标点预测模型：自动为识别结果添加逗号、句号、问号。
4. 时间戳对齐：将模型输出的 token 与音频时间轴对齐，支持点击跳转。

**7. 业务层加工**

- 段落重组：根据停顿、说话人切换自动换行分段。
- 过滤无效碎片：丢弃极短的杂音碎片。
- 摘要生成（可选链路分支）：将完整转写文本送入大模型生成纪要摘要。
- 持久化存储：转写文本、时间轴、原始音频落库。

**8. 返回结果**

前端获取完整转写文本、说话人信息、每个字 / 句的时间戳，以及可选的 AI 纪要。

### 两种模式链路差异

**实时录音模式（边录边转）**

`音频流式分片 → VAD 流式 → 增量 ASR 推理 → 增量后处理 → 流式返回文本`

该模式延迟较低，但存在局部修正现象：后续音频到达时，会修正前面识别错误的字。

**文件上传转写模式（离线转写）**

`完整音频一次性上传 → 全量预处理 → 全量 ASR 推理 → 全局后处理纠错、说话人聚类 → 返回完整结果`

该模式准确率更高，但延迟更高，没有增量修正。

### 技术架构特点

- 公有云 SaaS 方案：模型运行在飞书公有云集群。
- 非流式与流式双方案：分别面向离线妙记与会中实时识别场景。
- 深度绑定飞书生态：与日历、文档、任务管理模块无缝衔接。

### 链路常见故障点

1. 音频质量差：降噪失效会导致 ASR 识别出现乱字。
2. VAD 误判：把人声当作静音切掉，造成内容丢失。
3. 切片边界问题：一句话跨分片导致漏字。
4. 说话人聚类失败：多人对话被归为同一个说话人。
5. 标点模型效果差：转写结果通篇缺少标点。

## 使用场景

### 企业会议场景

适合企业例会、跨团队项目协作、客户访谈等。会议主持人通过飞书会议录制，结束后自动生成带时间轴的转写文本；无法参会的人员可通过妙记进行异步协作。

### 培训与公开课学习

上传录播课视频，利用妙记快速转写。复习时可直接搜索模糊知识点，比拖动进度条更高效。

### 访谈与调研记录

进行用户访谈或市场调研时全程录音并转为妙记，可对不同受访者针对相同问题的回答进行对比分析。

### 内容创作场景

适用于播客录制、采访稿生成、发布会内容整理等场景。

### 个人学习与灵感捕捉

记录碎片化思考，转成文字后便于整理与回溯。

## 操作方式

### 四种生成妙记的方式

| 方式 | 说明 |
|------|------|
| 录制飞书会议 | 主持人点击“开始录制”→“云录制”，会后自动生成 |
| 手机端录音 | 通过飞书 App 进入妙记，点击“录音”按钮 |
| 上传本地文件 | 在桌面端上传本地音频 / 视频文件（mp3、wav、m4a 等） |
| 导入飞书云端文件 | 从飞书云盘选择已有文件 |

通常 10 分钟的视频转写仅需 1-2 分钟即可完成。

### 查看与使用妙记

- 定位：点击文字任意字词跳转至音视频位置。
- 查找：在搜索框输入内容，结果自动高亮。
- 翻译：选择目标语言，文字记录自动翻译。
- 编辑：对文字记录进行增添、删除、修改。
- 高亮：选中文字标记重点信息。
- 评论：选中文字添加评论，@同事协作。
- 导出：导出为飞书文档、TXT、SRT 格式。

### 分享与权限

- 可将完整妙记分享给指定用户、群组、部门。
- 可创建并分享妙记片段。
- 可设置权限，控制谁能评论、分享、下载、导出。

## 版本与限制

### 版本差异

| 版本 | 妙记功能 | 月度转写额度 |
|------|---------|-------------|
| 基础版（免费） | 有限额度 | 300 分钟 / 月 |
| 商业版 / 企业版 | 额度不受限制 | 无限制 |

飞书基础版用户每个自然月可累计使用 300 分钟的妙记语音转文字功能。生成的妙记会占用企业存储空间。

### 国际版（Lark Minutes）

Lark 妙记（国际版）同样支持音视频转文字功能，但标准版和基础版用户无法使用语音转文字功能，仅专业版、旗舰版可用。

- 用户数据存储于国内合规云服务器。
- 通过网络安全等级保护三级。
