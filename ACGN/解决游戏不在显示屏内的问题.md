# 解决游戏不在显示屏内的问题

游戏画面超出显示器范围，且鼠标悬停时会直接切回桌面，这通常是因为**游戏的分辨率/刷新率与显示器不匹配**，或者**Windows 的缩放比例（DPI）导致了游戏窗口定位偏移**。

你可以按照以下几种由简到繁的方法来尝试解决：

### 1. 快捷键强行恢复窗口（最快的方法）

如果游戏目前处于活动状态（你可以听到声音，或者画面虽然错位但还在），尝试以下快捷键：

- **`Alt + Enter`**：这是切换“全屏”与“窗口化”的通用快捷键。很多时候按一下，游戏就会缩回正常的窗口模式，此时你就可以进游戏设置调整分辨率了。
    
- **`Win + Shift + 左/右方向键`**：如果游戏被移到了屏幕外面，这个组合键可以强行把当前窗口移动到其他监视器或重新居中。
    

### 2. 修改 Windows 缩放与分辨率设置

Windows 的高 DPI 缩放经常会导致老游戏或部分新游戏画面“爆框”。

1. 在桌面空白处右键，选择 **“显示设置”**。
    
2. 检查 **“比例与布局”**（通常是 100%、125% 或 150%）。记住当前的数值，然后试着将其**修改为 100%**。
    
3. 检查 **“显示器分辨率”**，确保它处于 **“推荐”** 状态。
    
4. 修改后，再次尝试打开游戏，看画面是否恢复正常。如果是缩放问题，可以在进游戏调好分辨率后，再把 Windows 缩放改回来。
    

### 3. 禁用改游戏程序的高 DPI 缩放

如果不想每次都改系统缩放，可以单独对这个游戏进行设置：

1. 找到该游戏的启动程序（`.exe` 文件，如果是桌面快捷方式，可以右键选择“打开文件所在的位置”）。
    
2. 右键点击该 `.exe` 文件，选择 **“属性”**。
    
3. 切换到 **“兼容性”** 选项卡。
    
4. 点击下方的 **“更改高 DPI 设置”**。
    
5. 勾选 **“替代高 DPI 缩放行为”**，并在下方的下拉菜单中选择 **“应用程序”**。
    
6. 点击确定并应用，重新运行游戏。
    

### 4. 通过配置文件强制修改游戏分辨率

如果游戏完全卡死在屏幕外，根本进不去设置菜单，可以尝试在游戏外修改分辨率：

1. 去电脑的 `文档`（Documents）文件夹、`C:\Users\你的用户名\AppData`（可能是 Local 或 Roaming），或者游戏安装目录下，寻找带有 `config.ini`、`setting.ini`、`options.txt` 等名字的文件。
    
2. 用记事本打开它，寻找 `WindowMode`、`DisplayMode`、`Width`、`Height` 或 `Resolution` 等字样。
    
3. 将分辨率强行改为你显示器的标准分辨率（例如 `Width=1920`, `Height=1080`），或者把全屏参数修改为窗口化（通常 `Windowed=1` 或 `Fullscreen=0`）。
    
4. 保存文件后重启游戏。
    

### 5. 显卡驱动控制面板调整

有时候显卡的缩放模式会导致这种冲突：

- **NVIDIA 显卡**：右键桌面打开 `NVIDIA 控制面板` -> `调整桌面尺寸和位置` -> 将缩放模式更改为 **“等比例”** 或 **“全屏”**，并在“执行缩放”上选择 **“GPU”**。
    
- **AMD 显卡**：打开 `AMD Software` -> `游戏` -> `显示器` -> 开启 **“GPU 缩放”**。
    

你可以先从 **`Alt + Enter`** 和 **修改 Windows 缩放** 开始排查，通常能解决绝大部分类似的问题。
