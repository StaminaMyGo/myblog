# Switch 模拟器（Eden）键盘键位设置指南

绝大多数 Switch 游戏主要围绕摇杆和字母按键（A/B/X/Y）来设计操作，所以默认键盘只映射了方向键，自然会觉得缺了不少按键。

要解锁完整的键盘操作，需要你手动进入 Eden 的设置菜单，为每个手柄按键绑定一个你习惯的键盘键位。具体步骤如下：

### ⌨️ 键盘键位设置步骤

1.  **进入设置**：打开 Eden 模拟器，点击菜单栏的 `模拟` (Emulation)，然后选择 `设置` (Configure)。
2.  **找到控制选项**：在弹出的设置窗口中，选择左侧的 `控制` (Controls) 标签页。
3.  **选择玩家**：确保顶部的“玩家”(Player)下拉菜单选择的是 `玩家1` (Player 1)。
4.  **开始按键映射**：
    *   你会看到一个 Switch 手柄的布局图，上面有 **A、B、X、Y**，以及 **L、R、ZL、ZR** 等所有按键。
    *   **用鼠标点击你想要设置的那个键**，例如“A”键。
    *   按钮变成“正在等待输入...”状态后，**按下你键盘上想设定的那个键**。
    *   比如，你可以把键盘的 `K` 键映射为 Switch 的 `A` 键，把 `J` 键映射为 `B` 键，把 `U` 键映射为 `X` 键，把 `I` 键映射为 `Y` 键，这样操作起来会比较顺手。
5.  **完成设置**：按你自己的习惯把所有按键都设置好后，直接关闭窗口，Eden 会自动保存你的配置。

### 🎮 常用按键参考

为了方便你快速上手，这里有一套经典且顺手的映射方案，你可以参考这个思路来设置：

| Switch 按键 | 推荐键盘映射 | 游戏中的常见功能 |
| :--- | :--- | :--- |
| **A** | `K` | 确认 / 对话 / 跳跃 |
| **B** | `J` | 取消 / 返回 / 冲刺 |
| **X** | `U` | 地图 / 特殊动作 |
| **Y** | `I` | 攻击 / 使用道具 |
| **+ (加号)** | `Enter` 或 `]` | 打开菜单 / 暂停 |
| **- (减号)** | `Tab` 或 `[` | 查看地图 / 设置 |
| **L** (肩键) | `Q` | 切换物品 / 防御 |
| **R** (肩键) | `E` | 使用技能 / 重攻击 |
| **ZL** | `Z` | 举起盾牌 / 瞄准 |
| **ZR** | `C` | 攻击 / 射击 |

> **特别说明**：对于大多数游戏来说，**左摇杆(L-Stick)控制角色移动，右摇杆(R-Stick)控制视角**。如果只用键盘，可以尝试在控制设置里找找“摇杆”的映射选项，绑定 `WASD` 四个键来模拟左摇杆。但一些需要精确控制视角的游戏，用键盘操作可能不太方便，这时候连接一个手柄体验会更好。

### 📝 几个小提示

*   **确保开启键盘输入**：在设置界面的“控制”标签页里，确认一下顶部的“输入设备”选项中，**已经选择了键盘(Keyboard)**，而不是“无”或其他设备。
*   **手柄是个好选择**：如果设置后发现很多游戏键盘操作起来还是别扭，可以考虑连接一个 Xbox 或 PS 手柄。Eden 对主流手柄的支持很好，通常插上就能直接使用，体验会好非常多。
*   **试试鼠标**：Eden 也支持模拟鼠标输入，在控制设置里找到“鼠标”(Mouse)相关的选项，可以把它映射成陀螺仪，在一些需要体感瞄准的游戏里会很有用。
