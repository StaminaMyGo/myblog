# 型月 × 飞碟社 × FGO 制作公司：Fate 帝国的权力三角

这三家公司（**型月**、**飞碟社**、**FGO 制作公司**）共同构成了当今日本 ACG 界最庞大、也最吸金的“Fate 帝国”核心权力三角。

用一句话来概括它们的关系：**型月（TYPE-MOON）是“造物主”和版权方，它把自家最核心的 IP（Fate/空之境界/魔法使之夜）分别交给了飞碟社去负责“动画降维打击”，交给了 FGO 制作公司负责“游戏疯狂吸金”。**

它们之间既有紧密的商业绑定，也有着极深的、长达近二十年的“革命友谊”。我们把这三者的复杂关系拆开来看：

## 一、 核心主角：三家公司分别是谁？

|**公司简称**|**官方名称**|**核心角色与定位**|
|---|---|---|
|**型月 (Type-Moon)**|有限会社ノーツ (NotesCo., Ltd.)|**原作、IP版权方。** 由奈须蘑菇（编剧）和武内崇（画师）创立。所有世界观（型月世界）和角色的老家。|
|**飞碟社 (ufotable)**|有限会社ユーフォーテーブル|**动画制作公司。** 业内顶尖的“特效作画大厂”。除了《鬼灭之刃》，它也是型月作品的“御用动画化御医”。|
|**FGO制作公司**|Lasengle (拉塞格尔)<br><br>  <br><br>_(原 Aniplex/DELiGHTWORKS)_|**游戏开发与运营方。** 专门负责《Fate/Grand Order》这款现象级手游的研发与维护。|

## 二、 错综复杂的“两两关系”

### 1. 型月 × 飞碟社：长达19年的“灵魂伴侣”

很多人是因为《鬼灭之刃》才知道飞碟社那堪称“经费燃烧”的呼吸法特效，但实际上，**飞碟社的一身神级光影特效本领，几乎全是当年在型月作品里“练兵”练出来的。**

- **结缘与蜜月：** 早在 2007 年，飞碟社就承接了型月的小说《空之境界》剧场版制作。当时他们一口气连做 7 部剧场版，凭借绝美的作画和梶浦由记的音乐一炮而红。
    
- **巅峰合作：** 随后，飞碟社接连制作了《Fate/Zero》（2011年）、《Fate/stay night [Unlimited Blade Works]》（2014年）以及《Fate/stay night [Heaven's Feel]》三部曲剧场版。
    
- **互相成就：** 业界戏称飞碟社社长近藤光是“全日本最大的月厨（型月粉丝）”。飞碟社对型月原作文本的还原度极高，武内崇和奈须蘑菇对飞碟社也近乎无限信任。型月给飞碟社供养了无数的版权费和死忠粉，飞碟社则用电影级的动画将型月 IP 推向了主流大众。
    

### 2. 型月 × FGO制作公司：从“草台班子”到“正规军”

《Fate/Grand Order》（FGO）这款手游改变了型月的命运，而负责制作和运营它的公司经历了一场大洗牌：

- **前身（Delight Works时期）：** FGO 在 2015 年刚上线时，是由一家叫 **Delight Works (DW)** 的小公司制作的。当时 DW 技术极烂，开服时经常服务器崩溃、程序Bug满天飞。但奈须蘑菇硬是靠着无敌的剧情把这款游戏抬到了世界流水前列。
    
- **现在的 Lasengle 时代：** 到了 2022 年，FGO 的母公司 **Aniplex**（索尼旗下动漫巨头）实在看不下去 DW 的摆烂了，直接出手把 DW 旗下的 FGO 整个开发团队打包收购，成立了一家新公司，取名叫 **Lasengle（拉塞格尔）**。
    
- **当前关系：** 现在的 Lasengle 是专门为了伺候 FGO 这尊财神爷而存在的。**型月负责出剧本、出角色设计（武内崇监修），Lasengle 负责把这些写进代码、做成游戏里的人物动作和关卡，并负责日常运营。**
    

### 3. 飞碟社 × FGO制作公司：微妙的“同门师兄弟”

这两家公司本身没有直接的股权关系，但它们**共同拥有一个超级大金主兼总发行商——Aniplex（索尼）**。

- FGO 手游每年的巨额流水（由 Lasengle 运营，Aniplex 收钱），有相当大一部分会被 Aniplex 拿去投资飞碟社的动画项目（比如《鬼灭之刃》、《魔夜》、《Fate》）。
    
- 飞碟社很少制作 FGO 游戏本身的动画（FGO 手游的短片和绝对魔兽战线等动画，大多由 Aniplex 旗下的另一家亲儿子 CloverWorks 制作），但飞碟社做过的 Fate 动画角色只要一进 FGO 卡池，就能帮 FGO 赚得盆满钵满。
    

## 三、 幕后的大Boss：Aniplex (索尼)

要真正看懂这三者的关系，必须提到幕后的“操盘手”——**Aniplex（简称A社）**。

```
          ┌─────────────────┐
          │  Aniplex (索尼) │ ◄──── 幕后大推手/总发行商/给钱给资源
          └──┬───────────┬──┘
             │           │
             ▼           ▼
      ┌───────────┐ ┌───────────┐
      │ 飞碟社     │ │ Lasengle  │
      │ (ufotable)│ │ (FGO制作) │
      └──────┬────┘ └────┬──────┘
             │           │
             │  动画化    │ 游戏化/剧本监修
             ▼           ▼
          ┌─────────────────┐
          │  型月 (TYPE-MOON)│ ◄──── 核心 IP 源头 (奈须蘑菇 / 武内崇)
          └─────────────────┘
```

Aniplex 凭借敏锐的商业嗅觉，把这三者牢牢绑在了一起：

1. 它从**型月**手里拿到了 Fate 的全方位开发权。
    
2. 它把动画交给**飞碟社**，砸重金宣发，打造出《Fate/Zero》《鬼灭之刃》等一个又一个社会级现象。
    
3. 它把游戏交给**Lasengle**（直接收为全资子公司），用手游把动画吸引来的流量变现为成百上千亿的日元。
    

这就是它们三者之间的商业闭环：**型月负责灵魂（内容），飞碟社负责皮囊（动画），FGO制作公司负责聚宝盆（游戏），三者缺一不可。**
