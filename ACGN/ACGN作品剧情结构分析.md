## 三、对话细节标准

1. 音效、画面、对话、心理都是感官
2. 减少重复描述
3. 内心想法添加的前提是读者能够 get
4. 可以有“纯对话”“纯心理”，但避免“纯客观”，需要客观和心理混合。

## 四、剧本结构（题材类型拆解）

1. **小众题材 + 美少女**（露营 / 网球 / 钓鱼 / 高尔夫 / 挖矿 / 农业）
   - 参考：《一杆青空》
2. **完整剧情架构 + 宏大世界观 + 美强惨**
   - 参考：《叛逆的鲁鲁修》《秽翼的尤斯提亚》《命运石之门》《变态监狱》
3. **美少女 + 乐队**
4. **萌豚**
5. **后宫**
6. **恋爱**
   - 恋爱关系确认前的拉扯与心动，是最好看的。
7. **党争**
8. **三角恋 / 多角恋**（胃药爱好者）
9. **地方宣传 / 文化宣传**
   - 参考：《神推偶像登上武道馆我就死而无憾》《败犬女主》
10. **特殊人士 / 三无系**
    - 参考：《谜之彼女》（口水）、《笨女孩》（捉弄笨蛋）、《古见同学有交流障碍症》（口吃 / 哑巴）、《声之形》（听障人士）
11. **福瑞控**
    - 参考：《动物狂想曲》《蜘蛛子（转生蜘蛛）》
12. **动画产业相关**
    - 参考：《白箱》《别对映像研出手》《16bit 的感动》
13. **异世界冒险**
    - 参考：《Re:0》《无职转生》《地狱乐》
14. **公路片**
    - 参考：《奇诺之旅》《混沌武士》
15. **日常类**
    - 参考：《间谍过家家》《日常》
16. **厕纸**（放弃大脑）
17. **神人番**
    - 参考：《男女之间的友情存在吗？（不，不存在!！）》
18. **装逼番**
    - 参考：《在下坂本》
