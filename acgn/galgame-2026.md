# Galgame 安利：近期通关记录

按通关时间倒序整理，附个人评分与推荐顺序。

## 《星轨之上》

- **类型**：科幻 / 治愈 / 全年龄
- **时长**：约 30 小时
- **简评**：近未来空间站题材，日常与主线节奏把控很好，
  音乐是加分项。缺点是共通线略长。

```text
剧情：★★★★☆
音乐：★★★★★
系统：★★★★☆
```

## 《梅雨之町》

- **类型**：青春 / 纯爱 / 全年龄
- **时长**：约 15 小时
- **简评**：小而美的作品，夏日与雨的味道拉满。
  适合一个周末一口气推完。

## 《幻夜协奏曲》

- **类型**：悬疑 / 剧情 / 全年龄
- **时长**：约 40 小时
- **简评**：多周目真相回收的教科书，但部分伏笔回收仓促。
  建议一周目不要看攻略。

## 推荐顺序

1. 想放松 → **《梅雨之町》**（短而甜）
2. 想要沉浸 → **《星轨之上》**（音乐+氛围）
3. 想烧脑 → **《幻夜协奏曲》**（多周目）

::: tip
入坑建议从全年龄作品开始，先确认口味再考虑更重度的作品。
:::

> 游戏是第九艺术，Galgame 是其中的小说家。
