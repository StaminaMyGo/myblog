# 雅思备考

## 一、总体建议

- 尽早按照机考环境练习：使用电脑做题、电脑打字，关闭输入法自动纠错，不依赖中文输入法的联想功能，以贴近真实考试状态。
- 大班课与冲刺班性价比有限。雅思考试信息透明度高，核心能力仍依赖自主练习，系统课程并非必选项。
- 建议投入付费的项目：AI 工具会员、写作人工批改、口语模拟测评、一到两次专项一对一辅导。
- 不建议购买宣称"短期暴涨"的课程或资料（如所谓"真经""三天 6.5""七天 7.5"），其效果缺乏可靠依据。
- 学习环境对专注度影响明显：优先选择图书馆或自习室，将手机放入包中，桌面只保留当前任务所需物品。

## 二、推荐日程

下表为一个可参考的每日安排，按精力曲线分配不同任务。

| 时间段 | 内容 |
| --- | --- |
| 9:00–12:00 | 背单词 + 复习单词 |
| 13:30–15:00 | 做真题，听力 / 阅读机考模拟 |
| 15:00–17:30 | 精听、复盘、记录错题 |
| 19:00–22:00 | 写作文、改作文、阅读写作 / 语法内容 |

## 三、单词背诵

- 每日新背 100–150 个，复习 150–200 个，保持高频重复。
- 判断标准：若在 3 秒内无法想起含义，即视为未掌握，不应自我放宽。
- 背单词不止记中文释义，还需同时记忆发音、拼写、单复数形式与常见搭配。
- 听力高频基础词需达到熟练：数字、月份、星期、颜色、国家名称，以及人名与地名的拼写。

## 四、听力训练

核心方法是精听，即在完成题目后逐句听写与比对，而非直接对照答案。

1. 完成题目后，先不查看答案解析。
2. 对错误或未听懂的句子进行单句精听：第一遍听；不懂听第二遍；仍不懂听第三遍。
3. 第三遍仍不懂，再查看原文或译文。
4. 若看原文仍无法理解，进行语法分析定位障碍。

::: tip Part 2/3 与 Part 1/4 的注意点
- 选择题、匹配题：听前快速将选项译为中文意思，降低听时认知负荷。
- 填空题：格外注意字数限制、单复数、拼写与大小写。
:::

错题应记录原因，常见类型包括：未听懂、定位错误、拼写错误、单复数错误、大小写错误。

## 五、阅读训练

- 不应只依赖"定位"技巧，本质仍需读懂句子与段落逻辑。
- T/F/NG 题型：可先读两道题，再读对应段落，减少回看。
- 填空题：先浏览关键词，读文章时顺手定位。
- 匹配题：不只找关键词，需把握整段主旨与逻辑。
- 遇到纠结题目不要死磕，单题分值有限，先完成后回看。

::: note 复盘应关注的问题
复盘时重点不是抄满生词，而是回答：题目问什么我读懂了吗？选项读懂了吗？原文对应句 / 段读懂了吗？问题出在语法、词汇，还是理解逻辑？
:::

## 六、写作训练

- 尽早动笔，即使初稿质量不高也应开始写，以暴露问题。
- 使用 AI 批改时，避免直接要求改为"九分范文"。更有效的指令是：请在我的原文结构与表达基础上，把这篇从 6 分水平改到 7 分水平，并解释每处修改原因；重点检查主谓一致、时态、单复数、拼写、指代与句子结构。
- 写作建议适当寻求教师或人工批改，因为针对性反馈对提升较关键。
