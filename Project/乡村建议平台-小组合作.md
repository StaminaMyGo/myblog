# 乡村助学平台（Rural Student Aid Platform）

> 项目类型：Web 前端应用（React + TypeScript）
> 文档版本：v1.0
> 生成日期：2026-08-15
> 别名：**乡村建议平台**（对应文件名《乡村建议平台-小组合作.md》，正文统一使用项目正式名称「乡村助学平台」）

---

## 一、项目背景

随着城乡教育资源差距的持续存在，乡村地区学生在获取优质师资、学习资源和心理辅导方面面临显著困难。传统的线下助学模式受地域、时间和人力成本限制，难以实现规模化、常态化的帮扶。

本项目旨在构建一个**线上乡村助学平台**，通过互联网技术将城市优质教师资源与乡村学生进行精准匹配，同时整合学习资源分发、实时沟通、心理支持和 AI 智能推荐等能力，打破地域壁垒，让乡村学生能够便捷地获得持续、高质量的教育帮扶。

平台采用多角色协同设计，涵盖学生、教师、家长和管理员四类用户，形成完整的助学闭环。

---

## 二、项目目的

1. **精准匹配**：通过 AI 智能推荐算法，根据学生的学科需求、年级、学习状况等维度，为其匹配最合适的教师资源。
2. **实时沟通**：提供基于 WebSocket 的即时聊天功能，支持学生与教师之间的实时答疑和学习交流。
3. **资源共享**：建立学习资源库，教师可上传和管理教学资料，学生可按需获取学习内容。
4. **心理支持**：关注乡村学生的心理健康，提供心理辅导和心理状态监测功能。
5. **家校协同**：家长端可查看孩子的学习进度、匹配状态和心理健康状况，实现家校联动。
6. **平台治理**：管理员端提供用户管理、内容审核、系统配置、AI 参数设置和日志审计等运营能力。

## 三、用户对象

| 角色 | 说明 | 核心诉求 |
| --- | --- | --- |
| **学生** | 乡村地区中小学生 | 找到合适的辅导老师、获取学习资源、实时答疑、心理支持 |
| **教师** | 志愿者教师 / 在线辅导教师 | 管理辅导学生、发送学习资料、在线答疑、查看学生情况 |

### 4.4 主要应用技术

#### 4.4.1 认证与权限

- **JWT 双 Token 机制**：Access Token + Refresh Token，Access Token 过期时自动调用刷新接口
- **Zustand 持久化存储**：认证状态通过 `persist` 中间件写入 localStorage，键名 `auth-storage-v2`
- **角色路由守卫**：`StudentProtectedRoute`、`TeacherProtectedRoute`、`AdminProtectedRoute`、`ParentProtectedRoute` 四层路由保护
- **统一登录态**：所有角色共用一个 `authStore`，通过 `role` 字段区分身份

#### 4.4.2 网络请求层

- **统一 Axios 实例**：baseURL 为 `/api/v1`，超时 45 秒
- **请求拦截器**：自动从 authStore 读取 Token 并注入 `Authorization` 头
- **响应拦截器**：直接返回 `response.data` 简化调用；401 错误自动触发 Token 刷新队列
- **错误防抖**：2 秒内相同错误不重复提示，避免消息轰炸
- **Vite 开发代理**：`/api` → `http://localhost:8080`，`/ws` → WebSocket 代理

#### 4.4.3 实时通信

- **原生 WebSocket**：聊天功能基于浏览器原生 WebSocket API
- **自定义 Hook**：`useWebSocket` 封装连接、消息收发、错误处理
- **自动重连**：最多 5 次重连尝试，指数退避策略
- **消息类型区分**：支持普通消息、系统消息、错误消息三种类型
- **微信风格布局**：发送方消息右侧气泡，接收方消息左侧气泡

#### 4.4.4 状态管理

- **Zustand**：主认证状态，轻量、支持 TypeScript、内置持久化
- **MobX**：部分业务模块使用，配合 `mobx-react-lite` 做细粒度响应式更新
- **本地状态**：页面级状态使用 React Hooks（useState、useEffect、useRef）

#### 4.4.5 UI 与样式

- **Tailwind CSS v4**：原子化 CSS，通过 `@tailwindcss/vite` 插件集成
- **双 UI 库并存**：Ant Design 6 + Arco Design 2.66，不同模块按需使用
- **响应式设计**：移动端单列、桌面端多列网格布局
- **图标体系**：lucide-react + @ant-design/icons 双图标库

#### 4.4.6 工程化

- **路径别名**：`@` 指向 `src` 目录
- **React Compiler**：通过 Babel 插件启用编译优化
- **TypeScript 严格模式**：`tsc -b` 构建前类型检查
- **ESLint**：代码规范检查，含 react-hooks、react-refresh 插件
