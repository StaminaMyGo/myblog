# 清北计算机系本科毕业论文（设计）要求

## 概述

本 Skill 面向清华大学与北京大学计算机科学与技术专业本科毕业生，系统梳理两校在毕业论文（设计）环节的共性要求与特色规范。清华计算机系本科培养方案要求总学分不低于 172 学分，其中"学士论文"（Bachelor Thesis）占一学期，学生需在科研实验室完成为期一学期的项目，撰写论文并通过答辩。北大计算机系毕业论文（设计）一般为 4 学分，要求完成从需求分析、概要设计、详细设计到代码实现、测试的全过程。

本 Skill 适用于毕业论文选题、撰写、格式规范及答辩准备全流程。

---

## 一、选题要求

### 1.1 选题原则

选题应符合专业培养目标，使学生在毕业论文工作过程中得到科学研究能力的基本训练。选题应满足以下要求：

- **实用价值**：选题应有一定的实用价值
- **难度与新意**：选题应有一定难度和新意
- **规模适中**：涉及的知识范围、理论深度应符合学生所学理论知识和实践技能的实际情况
- **一人一题**：原则上为一人一题，若采用同一大题目，每个学生须独立完成一个小专题

### 1.2 选题注意事项

- 毕业设计题目**不应含"系统"二字**
- "设计与实现"或"设计与开发"**五个字不能连用**
- 题目**不能太大，要有针对性**

### 1.3 选题类型

计算机专业毕业论文（设计）选题通常包括以下几类：

1. **软件开发型**：完成一个软件系统的需求分析、设计、实现与测试
2. **算法研究型**：针对某一算法问题进行理论研究、实验验证与改进
3. **系统设计型**：设计并实现一个硬件或软硬件结合的系统
4. **理论综述型**：对某一领域的研究现状进行系统综述与分析

## 二、内容与结构要求

### 2.1 基本要求

- **独立开发**：必须有独立开发的程序，完成从需求分析、概要设计、详细设计到代码实现、测试、试用乃至使用的全过程
- **代码规模**：程序应有一定规模，**不少于 2000 行代码**
- **演示要求**：能够根据导师要求做演示
- **学术规范**：论文应论据充分、逻辑清晰、文字通顺，遵守学术道德规范，严禁抄袭

### 2.2 论文整体结构

北大计算机系推荐的论文结构如下：

| 序号 | 章节 | 主要内容 |
|:---:|:---|:---|
| 前置 | 封面 | 题目、专业、学生姓名、导师姓名、时间 |
| 前置 | 摘要与关键词 | 三段式摘要，关键词不超过 5 个 |
| 前置 | 目录 | 采用自动生成方式 |
| 1 | 引言 | 主要工作的基础介绍，说明各章结构 |
| 2 | 开发背景与选题意义 | 国内外开发现状综述、研究热点与存在问题 |
| 3 | 需求分析 | 软件选型（硬件/软件平台及工具）、技术选型与比较 |
| 4 | 总体结构与功能设计 | 软件的总体架构与功能模块划分 |
| 5 | 各部分详细设计 | 突出有特色的部分 |
| 6 | 软件特点与实现难点 | 创新点与技术难点 |
| 7 | 使用或试运行情况 | 配以实例说明 |
| 8 | 总结与展望 | 归纳主要成果与创新之处，展望后续工作 |
| 末尾 | 参考文献 | 作者、文章名/书名、出版社、时间 |
| 末尾 | 附录（可选） | 重要代码片段、程序结构图、数据流图、数据库关系表、运行界面等 |
| 末尾 | 致谢 | 控制在一页内 |

> **重点章节**：第三、四、五章是论文的核心部分。每章可以分为若干节，**但不能有四级目录**，每章最后最好有本章小结。

### 2.3 写作注意事项

- **人称**：应采用**第三人称**论述，不使用第一人称
- **段落格式**：所有段落要求**首行缩进两个字符**
- **每章另起新页**
- **论述方式**：对各项内容要进行论述——**先提出问题，再提出解决思路，最后结合具体技术手段解决问题**，不能只是简单叙述和罗列
- **不能写成使用说明书或软件开发文档**
- **引用标注**：引用他人成果时须采用**上标方式**指明参考文献编号

## 三、格式与排版要求

### 3.1 页面与字体

- **纸张**：A4 纸
- **正文字号**：小四号（西文 12 号）
- **摘要字号**：小四号
- **摘要长度**：控制在一页内
- **打印方式**：单面打印
- **装订**：左侧用两个长尾夹装订

### 3.2 封面要求

- 封面应包含题目、专业、学生姓名、导师姓名、时间
- 封面**不能有页眉、页码**
- 具体的字体、字号请参照所在院系附录

### 3.3 装订顺序

论文应按以下顺序装订成册：

1. 封面
2. 目录
3. 中文摘要及关键词
4. 正文
5. 参考文献
6. 附录（可选）
7. 致谢

### 3.4 清华论文格式参考

清华大学本科生论文格式可参考教务处发布的《清华大学综合论文训练写作规范》。论文格式要求包括：

- 章节条理清楚、文字通顺
- 结果数据准确、图表清晰
- 论文篇幅约 **3 万字**

## 四、字数要求

| 项目 | 要求 |
|:---|:---|
| 清华计算机系本科论文 | 约 **3 万字** |
| 北大本科毕业论文 | 以 **10000 字左右**为宜 |
| 摘要 | 控制在一页内 |
| 致谢 | 控制在一页内 |

> 两校的具体字数要求可能因院系和指导教师而异，建议以所在院系最新规定为准。

---

## 五、过程管理要求

### 5.1 清华计算机系

- 学生需用**一学期**时间 dedicated to a project
- 项目来源于科研实验室，由教师指导
- 需完成论文并通过答辩

### 5.2 北大计算机系

- 毕业论文（设计）为 **4 学分**
- 需完成从需求分析到代码实现、测试的全过程
- 需通过**结题答辩**

### 5.3 通用要求

- **开题**：指导教师指导学生确定题目，指导开题
- **中期检查**：指导教师随时掌握进度和质量
- **评阅与答辩**：答辩时学生简述论文主要内容，回答答辩委员会提问

---

## 六、常见问题与注意事项

1. **论文与开发文档的区别**：毕业论文是对毕业设计实现过程的总结，需将具体技术上升到理论认识，不能写成使用说明书或软件开发文档

2. **代码规模的认定**：程序不少于 2000 行代码，需注意代码的原创性和规范性

3. **引用规范**：引用他人成果必须标注，采用上标方式指明参考文献编号

4. **学术诚信**：严禁抄袭、剽窃等学术不端行为

5. **格式一致性**：题目名称在任务书、论文封面、正文等处必须保持一致
