# 中山大学计算机学硕/专硕复试真题与经验汇总

## 一、复试总体结构与形式

中山大学计算机复试总分占入学总成绩的 50%，复试表现直接决定最终录取结果。不同年份和学院的复试形式有所差异：

| 年份 | 复试方式 | 构成 |
|------|----------|------|
| 2021 年 | 网络远程面试 | 综合评价 20% + 外语 20% + 专业能力及综合素质 60% |
| 2025 年 | 现场复试 | 面试为主，机试成绩供评委参考 |
| 早年（2018） | 现场复试 | 笔试 100 + 机试 + 英语 100 + 面试 300 |

计算机学院复试专业课通常为 **6705001 离散数学与 C 程序设计**。

## 二、笔试真题（CSDN / 知乎 / 王道论坛）

### 1. 离散数学

离散数学通常考 5 道大题，覆盖以下知识点：

- **命题逻辑与一阶逻辑**：求主析取范式、主合取范式、真值表。例如：用等值演算法证明 (¬p∧(¬q∧r))∨(p∧r)∨(q∧r) ⇔ r
- **一阶逻辑符号化**：如"所有的学生都修了数学课"等
- **关系与证明**：如果 R 是等价关系，证明 R∘R 也是等价关系
- **集合计数**：计算有多少人同时修了三门课
- **图论**：迪杰斯特拉最短路径
- **循环关系**：对循环关系的定义及相关证明

重点复习范围：命题逻辑、一阶逻辑、集合、关系、函数、图。群和代数系统自 2005 年后很少考到。

### 2. C 语言程序设计

C 语言题型包括选择题（20 分）、判断题（10 分）、编程题（20 分）。

- 参考教材：谭浩强《C 程序设计》，重点做课后习题
- **特别注意**：**文件操作**是高频考点，2018 年编程题 20 分就考了文件操作

### 3. 英语笔试（早年）

早年英语笔试包括：
- 中译英（如校长讲话翻译）
- 算法相关段落翻译
- 英语作文

### 难度与备考建议

- 机试共 10 道题，每题 100 分
- 难度相对基础，90 分以内涉及不到 DP，主要是**广搜、深搜、Prim 等基础算法**
- 必须掌握：**拓扑排序、求树的高度、判断图是否连通**等
- 推荐刷 LeetCode 或牛客网
- 机试不算入总分，但老师面试时能看到机试成绩，**coding 能力很重要**

## 四、面试真题（知乎 / CSDN / 经验帖）

面试通常**20 分钟以上**，无自我介绍环节，流程一般为：英语翻译 → 专业问答 → 项目深挖。

### 1. 英语能力测试

抽一段英文段落，**朗读 + 翻译**。段落主题多样：
- AI 相关、5G 网络、汽车制造、NP 问题等
- 商业类段落

备考建议：阅读 AI / 机器学习 / 大数据领域顶级论文的 abstract 或 introduction 并练习翻译。

### 2. 数学类问题（高频）

根据多位考生反馈，**数学问题是面试中的重点**，包括高数和线代：

| 问题 |
|------|
| 证明 √2 是无理数 |
| 什么样的函数没有原函数 |
| 什么是正定矩阵 |
| 两个矩阵相乘等于 0，则这两个矩阵一定有一个等于 0 吗？ |
| 矩阵的秩是什么 |
| 连续的定义 |
| 贝叶斯公式 |
| 方程解的情况 |
| 如何判断一个 n×n 矩阵可逆 |
| 如何在三维空间表示一条直线 |

### 3. 计算机基础（408 相关）

**操作系统**：
- 操作系统有什么功能
- Windows 和 UNIX 的区别
- 虚拟地址到物理地址的转换全流程

**数据结构与算法**：
- 面向对象的三个特征
- 贪心算法举例
- 迪杰斯特拉最短路径算法和哈夫曼编码是贪心算法吗？
- 数据结构的复杂度 O(1) 是什么意思
- 排序算法选一个讲基本思想

**数据库**：
- 数据库有哪些基本操作
- 范式、索引、锁、隔离、事务
- BCNF 范式

**其他**：
- 无监督学习和监督学习的区别
- 路由算法有哪些
- 流水线是什么，什么时候流水线不能继续
- C++ 的多态是什么
- C 中参数传递有哪些方法
- 形式系统的可靠性与完备性

### 4. 个人与项目问题

- 你选择的研究方向是什么？你觉得应该怎样开始一项研究工作？
- 你学过什么程序设计语言？它有什么特点？
- 谈谈你做过的一些项目经验
- 本科阶段哪些课程比较重要？它们之间有什么联系？
- 你来自哪个学校？原来学什么专业？
- 计算机领域有什么主要刊物
- 计算机界有什么主要企业
- 四六级成绩是多少？
- 如果你的分数不够，是否愿意调剂

### 5. 面试备考建议

1. **复试前一定要复习初试内容**，很多数学和 408 问题都是初试学过的
2. **对自己简历写的每一个专有名词都要十分透彻**
3. **对项目各种问题提前列一份问题清单**，尽量靠准备的内容回答
4. 准备一下每个项目自己的主要工作，老师问时尽量多说一点
5. 英语口语练好，机试成绩提高

## 六、注意事项

1. **真题获取受限**：考生需签署诚信复试承诺书，不得向他人透露考试题目，因此完整的官方真题难以获取，以上均为回忆版
2. **不同学院/研究所面试风格差异大**：计算机应用研究所和软件所等分开面试，风格差别很大
3. **年份差异**：不同年份的复试形式（线上/线下）、机试是否计入总分等有所不同，请以当年官方通知为准
4. **初试成绩直接给排名**，这是中大的优势，便于判断是否进复试
