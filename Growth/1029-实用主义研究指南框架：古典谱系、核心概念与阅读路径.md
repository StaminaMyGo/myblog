# 实用主义研究指南框架：古典谱系、核心概念与阅读路径

"实用主义研究指南"这个书名目前不能唯一对应到一本确定的中文书。最接近的可能是 *The Bloomsbury Handbook of Pragmatism*（Sami Pihlström 主编），它确实是一部面向研究者的实用主义手册；也可能是中文的《实用主义研究》系列论文集、陈亚军《实用主义：从皮尔士到布兰顿》，或周靖《剑桥实用主义研究》。下面按"实用主义研究"的整体框架整理。

> 核心命题：实用主义的要点不是简单的"有用即真理"，而是——一个观念如果没有任何可观察的实践差别，那它在哲学讨论中就没有清楚意义。知识不是旁观式的镜像，而是在探究和行动中形成的工具。

---

### 一、实用主义是什么

实用主义是 19 世纪 70 年代在美国形成的哲学传统。它强调观念、理论和信念的意义，要看它们在实践中产生什么后果；知识不是旁观式的镜像，而是在探究和行动中形成的工具。

---

### 二、关键人物与谱系

| 阶段 | 代表人物 | 关注重点 |
| :--- | :--- | :--- |
| **古典实用主义** | 皮尔士、詹姆斯、杜威、米德 | 意义准则、真理、经验、探究、民主与教育 |
| **新实用主义** | 奎因、罗蒂、普特南、布兰顿 | 语言、经验主义批判、真理、规范性与推论 |
| **当代扩展** | 舒克、米萨克、普莱斯等 | 科学、宗教、伦理、政治、美学、全球实用主义 |

- **皮尔士**更偏逻辑、科学方法和意义澄清；
- **詹姆斯**更偏心理、宗教经验和真理的"可接受性"；
- **杜威**把实用主义扩展到教育、民主、艺术和经验理论；
- **米德**则对社会自我、互动和共同体有重要贡献。

---

### 三、核心概念

| 概念 | 内容 |
| :--- | :--- |
| **实用主义准则** | 判断一个概念是否有意义，要看它会在经验中造成什么可检验的差别 |
| **真理观** | 真理不是静止的符合，而是在探究过程中被证实、能持续引导行动的观念 |
| **可错论** | 任何信念都可能被修正，哲学不应追求绝对不可动摇的基础 |
| **经验** | 经验不是被动感觉，而是有机体与环境之间的互动过程 |
| **探究** | 哲学问题应从具体情境出发，通过观察、假设、实验和反思来推进 |
| **民主与共同体** | 杜威等人把民主理解为一种生活方式，而不只是选举制度 |

### 四、阅读路径

**入门：**

| 书 | 价值 |
| :--- | :--- |
| 威廉·詹姆斯《实用主义》 | 入门经典 |
| 杜威《哲学的改造》或《确定性的寻求》 | 杜威经验理论入口 |
| 舒克《实用主义》 | 当代概述 |
| 陈亚军《实用主义：从皮尔士到布兰顿》 | 从古典到新实用主义线索 |

**研究层面：**

- 刘放桐、陈亚军主编《实用主义研究》第一、二辑；
- 孙宁《古典实用主义的线索与视域》；
- 周靖《剑桥实用主义研究》；
- *The Bloomsbury Handbook of Pragmatism*。

### 六、容易误读的地方

不要把实用主义理解成"只要有用就正确"。皮尔士和杜威都强调科学探究、公共检验和长期后果；詹姆斯虽然更重视个体经验和信仰意志，但也不是主张任意相信。

另外，古典实用主义更重视经验、行动和探究；新实用主义更多进入语言、逻辑和规范性问题。两者有连续性，但问题意识已经发生变化。

### 七、专业名词释义

| 术语 | 英文 | 核心概念 | 来源/背景 | 解决什么问题 |
| :--- | :--- | :--- | :--- | :--- |
| **实用主义** | Pragmatism | 以实践后果判定观念意义的哲学传统 | 皮尔士/詹姆斯/杜威 | 澄清概念意义 |
| **实用主义准则** | Pragmatic Maxim | 概念意义在于可检验的实践差别 | 皮尔士 | 检验概念有无意义 |
| **可错论** | Fallibilism | 一切信念原则上可被修正 | 皮尔士 | 拒斥绝对基础 |
| **探究** | Inquiry | 从情境出发的观察-假设-实验-反思过程 | 杜威 | 替代旁观式认识 |
| **真理观** | Theory of Truth | 真理为探究中可证实、可引导行动的观念 | 詹姆斯/杜威 | 反驳符合论僵化 |
| **新实用主义** | Neopragmatism | 从经验转向语言与规范性的实用主义阶段 | 罗蒂/布兰顿 | 回应语言学转向 |
| **推论语义学** | Inferential Semantics | 以推理关系界定概念内容的语义理论 | 布兰顿 | 重新奠基语义学 |
| **经验主义批判** | Critique of Empiricism | 对传统感觉经验论的批评 | 新实用主义 | 摆脱基础主义 |
| **民主作为生活方式** | Democracy as a Way of Life | 民主不只是选举制度而是共同体生活方式 | 杜威 | 扩展民主内涵 |
