# 销售圣经双版本拆解：吉特默戒律与威奇斯勒流程

《销售圣经》这个书名对应着多本不同的书。最可能指的是杰弗里·吉特默的《The Sales Bible》，这是流传最广、被引用最多的一本。

> 核心命题：销售的核心不是话术技巧，而是"思考、相信、投入"等态度戒律与流程纪律的组合——吉特默版强调态度与友谊驱动，威奇斯勒版强调流程与漏斗管理。

---

### 一、杰弗里·吉特默版《销售圣经》

吉特默自称"职业销售员"，全书基于数十年街头销售经验，而非学术理论。核心框架是**"10.5 条销售成功戒律"**：思考、相信、投入、发现、提问、观察、敢为、担责、赢得、证明，以及半步"成为"。

| 部分 | 核心内容 |
| :--- | :--- |
| **第一部分：规则、秘密与乐趣** | "AHA 公式"（态度+幽默+行动）；50% 以上的销售建立在友谊基础上，让潜在客户笑出来是最快的建立融洽关系的方式 |
| **第二部分：准备** | "WOW 因子"——做到与众不同的能力；"强力陈述"：用客户世界里的语言描述产品利益 |
| **第三部分：建立联系** | 打造 30 秒个人广告、处理推荐、用间接方式冷启动 |
| **第四部分：演示** | 建立买家信心、让客户身体参与、改进幻灯片演示 |
| **第五部分：异议、成交与跟进** | 区分真异议和拖延，给出七种常见异议的应对脚本；"小狗成交法"（让客户在承诺前先拥有） |
| **第六部分：关系网络** | 销售目标不是单次成交，而是长期利润；制定五年社交计划，核心原则是"先给予，不记账" |

---

### 二、沃伦·威奇斯勒版《销售圣经》

另一版本的框架是"销售三要素"：**销售（流程）、人、术**。流程分五阶段：**准备 → 介绍 → 说服 → 成交 → 告别**。核心思想是"金字塔式销售流程"和"漏斗/管线理论"。

```text
威奇斯勒销售流程：
准备 → 介绍 → 说服 → 成交 → 告别
    ↓
金字塔式流程（逐层推进）
    ↓
漏斗/管线理论（持续输入机会，量化转化）
```

---

### 三、两版对比

| 维度 | 吉特默版 | 威奇斯勒版 |
| :--- | :--- | :--- |
| **基础** | 街头销售经验 | 流程方法论 |
| **核心框架** | 10.5 条戒律 | 销售三要素（销售/人/术） |
| **重心** | 态度、友谊、关系 | 流程、漏斗、管线 |
| **代表性概念** | AHA 公式 / WOW 因子 / 小狗成交法 | 五阶段流程 / 金字塔流程 |

### 四、专业名词释义

| 术语 | 英文 | 核心概念 | 来源/背景 | 解决什么问题 |
| :--- | :--- | :--- | :--- | :--- |
| **AHA 公式** | Attitude-Humor-Action | 态度+幽默+行动的销售组合 | 吉特默 | 建立融洽关系 |
| **WOW 因子** | WOW Factor | 做到与众不同的差异化能力 | 吉特默 | 从平庸中脱颖而出 |
| **强力陈述** | Power Statement | 用客户语言描述利益的陈述 | 吉特默 | 精准传达价值 |
| **小狗成交法** | Puppy Dog Close | 让客户先拥有再决定是否购买 | 销售技巧 | 降低成交心理门槛 |
| **异议处理** | Objection Handling | 应对客户拒绝理由的脚本化方法 | 销售方法论 | 排除成交障碍 |
| **漏斗/管线理论** | Sales Funnel / Pipeline | 将机会按阶段量化管理的模型 | 销售管理 | 预测与把控成交 |
| **跟进** | Follow-Up | 成交后的持续关系维护 | 销售实践 | 创造复购与转介绍 |
| **冷启动** | Cold Start | 无既有关系的新客户接触 | 销售实践 | 拓展新客源 |
