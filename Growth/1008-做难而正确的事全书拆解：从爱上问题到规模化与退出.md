# 做难而正确的事全书拆解：从爱上问题到规模化与退出

《做难而正确的事》作者是以色列企业家尤里·莱文（Uri Levine），导航应用 Waze 的联合创始人。这本书基于他创立两家估值超 10 亿美元公司的实战经验，系统拆解了创业全流程。全书共 13 章，大致可分为三个部分。

> 核心命题：创业的核心是聚焦真实且普遍的问题而非执着于解决方案，快速失败、快速调整；每个阶段只专注一件事，产品市场契合点（PMF）永远是第一优先级；规模化阶段需以经常性收入与健康单位经济模型为根基。

---

### 一、创业底层逻辑（第 1-3 章）

| 章 | 核心观点 |
| :--- | :--- |
| **第 1 章：爱上问题，而不是解决方案** | 聚焦真实且普遍的问题，而非自认为完美的解决方案；成功初创公司往往源于创始人对痛点的强烈体感，且该问题能引发广泛共鸣 |
| **第 2 章：勇于面对失败，而且快速失败** | 创业本质是"失败之旅"；快速试错、快速调整是缩短成功路径的关键；接受"穿越沙漠"般的无进展阶段，核心是保持资金和方向稳定 |
| **第 3 章：拥抱颠覆，拥抱对颠覆的颠覆** | 颠覆的核心是改变市场供需平衡与用户行为模式，而非单纯技术创新；颠覆者多为"麻烦制造者"，通过透明度打破信息不对称的市场 |

---

### 二、创业关键动作（第 4-9 章）

| 章 | 核心观点 |
| :--- | :--- |
| **第 4 章：每个阶段只专注做一件事** | 分阶段聚焦核心目标；**产品市场契合点（PMF）永远是第一优先级**，之后再推进商业模式、规模化，避免注意力分散 |
| **第 5 章：跳好已经被拒绝 100 次的"舞蹈"** | 融资核心是让投资人认可 CEO 与创业故事；打造有情感共鸣的叙事，直面无数次拒绝，善用"害怕错过"心理推动交易 |
| **第 6 章：你的工作是让公司成功，而不是让别人满意** | 管理投资人与董事会：保持透明、引导决策、直面利益冲突；核心目标是公司长期成功，而非短期讨好 |
| **第 7 章：解雇比招聘更重要** | 快速解雇不合适的员工是保护优秀人才的关键；公司 DNA 需从创立之初定义；招聘聚焦"能实现结果、适配文化"的人 |
| **第 8 章：从情感上深刻打动新用户** | 用户分为创新者、早期采用者、早期大众等类型，需理解差异并保持产品简单易用；**首次使用体验决定用户留存** |
| **第 9 章：要么找到产品市场契合点，要么去死** | PMF 的核心衡量指标是**转化率与留存率**；通过用户漏斗模型消除障碍，迭代产品直至"足够好" |

---

### 三、规模化与长期发展（第 10-13 章）

| 章 | 核心观点 |
| :--- | :--- |
| **第 10 章：努力提升盈利能力** | 商业模式需基于用户价值；优先选择能带来经常性收入的模式（如订阅制）；确保 **LTV（用户生命周期价值）至少是 CAC（用户获取成本）的 3 倍** |
| **第 11 章：获得 10 亿用户的增长** | 先通过营销或业务开发积累临界用户量，再依靠口碑实现指数级增长；准备 50 种以上用户获取方法并持续试错 |
| **第 12 章：找到全球化的新路径** | 本土市场较小时需从创业第一天考虑全球化；优先选择"易胜出且体量较大"的市场，同时布局 3-5 个国家验证策略 |
| **第 13 章：终点就是起点** | 探讨股权退出的影响与形式；退出前最好先有一笔交易摆在桌面上，并与收购方探讨共同的未来 |

```text
创业全流程路线：
爱上问题 → 快速失败 → 拥抱颠覆
    ↓
阶段聚焦（PMF 第一优先级）→ 融资叙事 → 管理董事会
    ↓
解雇优化 → 打动新用户 → 找到 PMF（转化率 + 留存率）
    ↓
盈利能力（LTV ≥ 3×CAC）→ 指数增长 → 全球化 → 退出
```

### 四、与左晖《详谈》的区分

左晖（贝壳找房、链家创始人）也有一本相关访谈录《详谈：左晖》，副标题同为"做难而正确的事"，由李翔撰写。它记录的是左晖的商业理念，而非系统的创业方法论。

| 维度 | 莱文《做难而正确的事》 | 李翔《详谈：左晖》 |
| :--- | :--- | :--- |
| **体裁** | 系统的创业方法论 | 人物访谈录 |
| **作者** | 创业者本人 | 记者李翔 |
| **内容** | 创业全流程拆解 | 商业理念与行业思考 |

### 五、专业名词释义

| 术语 | 英文 | 核心概念 | 来源/背景 | 解决什么问题 |
| :--- | :--- | :--- | :--- | :--- |
| **产品市场契合点** | Product-Market Fit (PMF) | 产品恰好满足真实市场需求的状态 | 硅谷创业方法论 | 判定创业阶段优先级 |
| **用户生命周期价值** | Lifetime Value (LTV) | 单个用户在其生命周期内创造的总收入 | 增长经济学 | 衡量用户长期价值 |
| **用户获取成本** | Customer Acquisition Cost (CAC) | 获取一个新用户所需的总成本 | 增长营销 | 评估获客效率 |
| **用户漏斗** | Funnel | 从曝光到转化的用户流失过程模型 | 转化分析 | 定位流失环节 |
| **颠覆式创新** | Disruptive Innovation | 改变市场结构与行为模式的创新 | 克里斯坦森 | 解释新进入者机会 |
| **创新者/早期采用者** | Innovators / Early Adopters | 技术采纳曲线的早期用户群体 | 罗杰斯扩散理论 | 细分用户策略 |
| **信息不对称** | Information Asymmetry | 交易各方掌握信息不对等的状态 | 信息经济学 | 解释透明度的价值 |
| **股权退出** | Equity Exit | 创始人通过出售股权/公司实现的退出机制 | 风险投资 | 实现资本回报 |
