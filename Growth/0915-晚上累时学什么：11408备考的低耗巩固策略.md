# 晚上累时学什么：11408 备考的低耗巩固策略

先给结论：**晚上很累时，不要再追求"新进度、高难度、长时间"，而是切换到"低认知负荷、可量化、能巩固"的任务。** 学习量不一定要用"小时"算，可以用"完成任务数"算。**真累到头晕、心悸、看不进字，直接睡，睡眠本身就是 11408 备考的隐藏科目。**

## 一、先判断：你是真累还是假累

| 状态 | 表现 | 对策 |
| :--- | :--- | :--- |
| 假累 | 坐久了、眼睛酸、脑子还能转 | 换脑 + 低耗任务 |
| 真累 | 头痛、心慌、看字不进、情绪烦躁 | 休息/睡觉，别硬撑 |
| 长期累 | 连续一周晚上都废 | 调整白天计划 + 睡眠 + 运动 |

## 二、晚上累时，适合做什么？

原则：

::: tip 任务选择原则
**复盘 > 新学**
**背诵 > 理解**
**选择题 > 大题**
**整理 > 攻坚**
**短反馈 > 长反馈**
:::

### 1. 数学一

- 背公式：泰勒、积分表、常见导数、级数展开
- 看白天错题，只重做 1–2 道计算小题
- 默写定理条件，不碰新证明题
- 整理一类题的步骤模板

### 2. 408

- 画思维导图/框架图
- 背常考概念：Cache、中断、进程状态、TCP 状态机
- 看王道错题，做选择题
- 口述算法思想，不硬写完整代码
- 复盘白天大题思路，不重新死磕

### 3. 英语一

- 背单词 / 复习真题词汇
- 精读一段真题，分析 1–2 个长难句
- 听英文材料放松，不追求全懂
- 默写作文模板句（如果还有精力）

### 4. 政治

- 刷选择题
- 背帽子题、时间线、会议、关键词
- 看思维导图
- 听带背音频，躺着听也行

## 三、按疲劳程度安排晚上

| 疲劳等级 | 可做任务 | 时长 |
| :--- | :--- | :--- |
| 有点累 | 错题复盘 + 背诵 + 选择题 | 1.5–2h |
| 明显累 | 背单词/政治 + 看错题 + 框架 | 1h |
| 非常累 | 写明日计划 + 过今日错题标题 + 听音频 | 20–30min |
| 极度累 | 洗漱睡觉 | 0 |

**最低维持量：30 分钟复盘 + 20 分钟背诵 + 10 分钟计划。** 这已经能维持学习惯性，不算过劳。

## 四、推荐晚上流程

1. **先离线休息 20–30 分钟**：散步、洗澡、拉伸、闭眼，不要刷手机。
2. **45 分钟低耗任务 + 10 分钟休息**：只做 2–3 件，比如错题复盘、背单词/政治、408 选择题。
3. **睡前 10 分钟规划明天**：写下明天三件最重要的事，降低第二天启动成本。
4. **23:00 前睡**：熬夜补的量，第二天会加倍还回去。

## 五、晚上累时不要做

- 新数学证明题、新 408 大题
- 硬写英语作文
- 开新章节、看长视频课
- 边刷手机边学
- 用咖啡硬撑到凌晨
- 因为晚上没学够而自责，然后熬夜

## 六、如果长期晚上都累

说明问题不在晚上，而在白天：

- 最难的任务放上午
- 下午安排输出型任务
- 晚上只复习，不攻坚
- 午休 20–30 分钟
- 每周留半天彻底休息
- 保证 7–8 小时睡眠
- 每天 20–30 分钟运动

::: tip 一句话总结
晚上累时，学习量靠"低耗巩固任务"维持，不靠硬扛；复盘、背诵、选择题、计划就是 11408 考生的夜间保底任务，真累就睡，睡眠也是备考。
:::
