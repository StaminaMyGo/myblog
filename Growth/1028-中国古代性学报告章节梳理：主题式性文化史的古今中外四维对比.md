# 中国古代性学报告章节梳理：主题式性文化史的古今中外四维对比

《中国古代性学报告》由中国社会科学院研究员冯国超撰写，华夏出版社 2013 年出版初版，2014 年出版增补版。书名虽然借用"性学报告"的体例，但它并非像《金赛性学报告》《海蒂性学报告》那样依靠问卷和调查数据，而是以古代房中书、医书、野史、笔记、明清艳情小说、春宫画和秘戏图等材料为基础，按现代性学主题重新编排。

> 核心命题：全书是主题式性文化史读本而非实证研究报告——以古代材料为基础、按现代主题编排，其价值在于呈现中国古代身体观与性别观念的完整图景，而非提供现代医学结论。

---

### 一、基本体例

全书采用"古今中外四维对比"的写法：先介绍中国古代某个性学主题的观点，再对照西方性学相关理论，再引入现代医学或现代性学判断，最后作出评价。这种体例使它更像一部主题式性文化史读本，而不是严格意义上的实证研究报告。

### 二、十三章概览

| 章 | 主题 | 核心内容 |
| :--- | :--- | :--- |
| **第一章** | 性与中国古代的婚姻家庭 | 一夫多妻制、贞操观、节妇制度、婚外性行为和生育观念；婚姻制度既涉及家庭秩序也涉及性资源分配；贞操观念与女性身体控制密切相关；生育方面长期受"重男轻女"观念影响 |
| **第二章** | 性心理 | 性与情的分离与融合、性欲激发因素、性幻想、性虚伪；古代对女性性欲的观察；文学作品中大量性心理描写反映当时社会的欲望结构 |
| **第三章** | 性交的利弊与性交禁忌 | 性交频率、性交对健康的影响、男女在性反应上的差异、传统房中术中的"避忌"；古人既承认性交能带来愉悦，也担心过度消耗，主张节制与调和 |
| **第四章** | 性交姿势与性交技巧 | 古代房中书中关于姿势、技巧、口交、肛交、手淫等内容；多出自《素女经》《洞玄子》等房中传统及明清小说，需放在古代养生、医学和文学语境中理解 |
| **第五章** | 性高潮 | 女性性兴奋与性高潮、男性性高潮与射精；把古代"取悦女性""阴阳和谐"等说法与现代性学对高潮机制的解释进行对照 |
| **第六章** | 助性手段 | 春宫画、色情文学、性玩具；"角先生""缅铃"等古代助性器具；三寸金莲等特殊身体审美与性刺激之间的关系 |
| **第七章** | 提高性能力的方法 | 按摩、气功修炼、春药、房中养生；古代性能力观念往往与养生、延年、保精联系在一起，但其中不少说法缺乏现代医学验证 |
| **第八章** | 性器官的大小、形状与功能 | 古人对男女生殖器官外观、功能及优劣的评价；呈现大量民间观念，提醒读者区分经验性描述、审美偏见和现代解剖生理学知识 |
| **第九章** | 不同类型的人与性 | 双性恋、阴阳人、太监、娼妓、出家人、老年人、处女等群体；展示古代社会中性身份的复杂性 |
| **第十章** | 同性恋与同性性行为 | 男性同性恋和女性同性恋的历史记载与社会态度；古代中国对同性性行为并非始终以现代意义上的"同性恋身份"来理解，更多出现在权力关系、情感关系和文学叙事中 |
| **第十一章** | 性与疾病 | 性病、性功能障碍、房中禁忌与健康风险；古代医学常把性与气血、脏腑、阴阳联系起来，既有经验观察也有理论化推测 |
| **第十二章** | 非常态性行为 | 增补版重点增加；涉及古代文献和小说中记载的异常性行为、特殊癖好及边缘性实践 |
| **第十三章** | 房中功夫 | 房中术核心理念，如"多交不泄""还精补脑""采阴补阳"；一方面呈现其养生理论，另一方面指出其中存在性别偏见和现代医学争议 |


### 四、应用场景与阅读提示

**应用场景：**

| 场景 | 用法 |
| :--- | :--- |
| **性文化史研究** | 了解中国古代婚姻、生育、贞操和房中术观念 |
| **文学研究** | 帮助理解明清小说中性描写的社会背景 |
| **性别研究** | 分析古代女性身体、贞操制度和性别权力关系 |
| **医学史阅读** | 区分传统养生观念与现代性医学 |
| **大众科普** | 认识"房中术"并非单纯色情，而是古代身体观的一部分 |

> **阅读提示**：这本书资料丰富，但性质更接近性文化史与性学主题汇编。强项在于材料广、主题全、可读性强；不足在于部分结论依赖小说、野史和房中书，不能直接当作现代医学或社会学调查结论。更严肃的学术对照可搭配高罗佩《中国古代房内考》，后者在文献考证和社会史分析上更系统。
