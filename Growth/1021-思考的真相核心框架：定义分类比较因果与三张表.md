# 思考的真相核心框架：定义分类比较因果与三张表

《思考的真相》是李笑来 2024 年出版的一本极薄的小书，全书仅约 2 万字。它的核心主张是：**思考不是玄学，而是一套可以拆解、可以练习的"手艺活"**。书里把思考拆成了几个基础动作，认为掌握它们就能应对生活中绝大多数决策。

> 核心命题：一切决策都是定义、分类、比较、因果的组合应用；加上时间维度的耐心迭代，人就能从"想不清楚"走向"做得到位"。思考框架的终点是行动。

---

### 一、基础：思考的四件套

这是全书的核心框架，认为一切决策都是**定义、分类、比较、因果**的组合应用，且有微妙的先后顺序。

| 动作 | 要点 |
| :--- | :--- |
| **定义** | 关键是**等号左边有必要，等号右边无歧义**；概念模糊，后续全错。比如把"消费"当成"投资"、把"脾气大"当成"真性情"，定义错了决策必然偏 |
| **分类** | 要**合理且完整**：子类之间互不重合（合理），所有子类加起来等于整体（完整），即"不重不漏"；全面思考的本质是分类做得足够好 |
| **比较** | 前提是**同一范畴、相同属性**；苹果和香蕉都是水果可以比口感，苹果和汽车不能比；客观比重越大，比较结果越准确 |
| **因果** | 追问模板：A 真的是 B 的原因吗？A 是 B 的唯一原因吗？如果不是，还有哪些？谁是最重要的？普通人最实用的策略是"采用真专家的研究结论" |
| **决策** | 每一个决策无论大小，背后都是四者的组合应用，实际应用是嵌套进行的 |
| **流程** | 描述任何事情无非"什么、为何、如何"；所有流程由三种模块组成：**顺序、循环、判断与分支**；做事的本质是对流程的规划和管理，提高效率就是对流程的优化 |

---

### 二、进阶：给思考加上时间维度

| 节 | 核心内容 |
| :--- | :--- |
| **关系** | 定义清楚后，分类、比较、因果分析这三个动作确定事物之间的关系 |
| **维度** | 引入**时间维度**看问题；"性格决定命运"其实是一维因果，真相是性格与命运互为因果、相互塑造；**贝叶斯定理**是重要工具：根据新证据不断修订对概率的判断 |
| **未知** | 面对复杂系统，谁都无法从一开始精确预测长时间迭代后的结果；能做的就是去行动、去迭代 |
| **曙光** | 在混沌中看到规律涌现的可能，意味着方向开始清晰 |

---

### 三、返璞：回到最简单的工具

| 节 | 核心内容 |
| :--- | :--- |
| **类比** | 为理解陌生的 X，找一个熟悉的 A，在 X 和 A 之间画约等号；类比是跨越已知与未知的桥梁，也是"举一反三"的底层机制；**约等于不是等于**，桥只是用来过河的，不是对岸本身 |
| **发展** | **时间是发展的唯一路径**；发展就是迭代简单的事；核心公式：**极致简单 × 无限迭代 = 极度复杂 / 意外精彩** |
| **简单** | 面对复杂世界，反过来找更简单的东西作为工具；反复问自己"什么更重要"，这个简单动作的无限迭代，最终会涌现出价值观 |
| **升级** | 每个人脑子里有三张表：**概念表（认知）、关系表（判断）、流程表（行动）**；学习、思考、行动本质上都是对这三张表的"增删改查"；所谓升级就是不断更新这三张表 |

```text
思考的四件套：
定义（等号右边无歧义）→ 分类（不重不漏）
    ↓
比较（同一范畴）→ 因果（追问模板）
    ↓
决策（四者嵌套组合）
    ↓
时间维度（贝叶斯修订 + 迭代）
    ↓
三张表升级（概念表/关系表/流程表）
```

### 四、专业名词释义

| 术语 | 英文 | 核心概念 | 来源/背景 | 解决什么问题 |
| :--- | :--- | :--- | :--- | :--- |
| **定义** | Definition | 为概念划定清晰边界的动作 | 逻辑学 | 保证概念无歧义 |
| **分类** | Classification | 按标准将对象划分到子类 | 逻辑学 | 实现不重不漏 |
| **比较** | Comparison | 在相同范畴属性间衡量差异 | 逻辑学 | 保证比较有效 |
| **因果** | Causality | 追问原因与结果关系 | 科学方法 | 识别真正原因 |
| **贝叶斯定理** | Bayes' Theorem | 依据新证据更新先验概率的方法 | 概率论 | 动态修正判断 |
| **类比** | Analogy | 以熟悉之物理解陌生之物的桥梁 | 认知科学 | 跨越已知与未知 |
| **迭代** | Iteration | 反复循环改进的过程 | 系统科学 | 驱动复杂涌现 |
| **涌现** | Emergence | 简单规则反复作用产生复杂结果的现象 | 复杂系统科学 | 解释迭代价值 |
| **概念表/关系表/流程表** | Concept / Relation / Process Table | 认知、判断、行动三张心智表 | 李笑来 | 界定升级对象 |
