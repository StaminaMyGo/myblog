# 被败坏的学术核心梳理：科研四类问题与开放科学改革

《被败坏的学术：科研中的造假、偏见、疏忽与炒作》是英国心理学家斯图尔特·里奇所著，2026 年 6 月由新华出版社出版中译本，曾获《泰晤士报》2020 年度好书、英国皇家学会 2021 年度科学图书奖提名。全书并非简单否定科学，而是站在科学内部，批评当前科研激励和评价体系如何侵蚀科学的可信度。

> 核心命题：科学之所以值得信任，不是因为它从不犯错，而是因为它应当拥有更强的纠错能力。当激励系统只奖励"好看的结果"而不奖励"可靠的结果"时，科学就会偏离自己的初衷。

---

### 一、第一部分：科学为何会出错

| 主题 | 核心内容 |
| :--- | :--- |
| **科学与"社会建构"** | 科学不是孤独天才独自发现真理，而是由人参与的社会活动。科学家会犯错、会护短、会偷懒，也会受职业压力影响。科学的可靠性不来自科学家个人完美，而应来自公开、重复、审查和纠错的制度安排 |
| **复现危机** | 心理学、医学、生物学、经济学等领域出现大量研究无法被重复验证的问题。2015 年一项心理学重复研究中，原始研究有 97% 报告显著结果，重复后仅剩 36% 能复现，效应量也明显下降。"启动效应""成长型思维"、睡眠与营养、基因与微生物组等流行结论，都曾被质疑基础并不牢固 |

---

### 二、第二部分：四类问题如何败坏科学

| 问题 | 定义 | 典型案例 |
| :--- | :--- | :--- |
| **造假** | 蓄意伪造、篡改数据或图像 | 意大利外科医生保罗·马基亚里尼的气管移植丑闻：研究曾被顶级期刊发表，但多名患者术后死亡或遭受严重伤害，机构长期未能有效纠错 |
| **偏见** | 研究者即使没有恶意，也可能被无意识偏见影响 | 典型问题包括 p 值操纵、选择性报告、发表偏倚：期刊更愿意发表"阳性""新颖""惊人"的结果，大量阴性结果被埋没 |
| **疏忽** | 统计误用、实验设计粗糙、数据处理不严谨 | 相比蓄意造假更普遍也更隐蔽：常发生在诚实研究者身上，却同样会产出不可靠结论 |
| **炒作** | 研究者、大学、媒体和出版商夸大研究意义 | 《科学》杂志曾发表"细菌可用砷替代磷构建 DNA"的论文引发轰动，后来被证明更可能是实验污染所致 |

### 三、第三部分：制度性根源

| 根源 | 机制 |
| :--- | :--- |
| **"不发表，就出局"的压力** | 职业晋升、基金申请、学校排名、期刊影响因子和引用量共同塑造科研激励；系统更奖励"发得出""够新颖""有话题"的成果，较少奖励"验证得牢""结果阴性""过程透明"的研究 |
| **同行评议并不等于可靠保证** | 同行评议能过滤明显问题，但通常不会逐条核对原始数据、代码和实验过程；科学依赖信任，而信任可能被造假者、疏忽者或炒作机制利用 |
| **机构也可能失灵** | 大学、期刊和资助机构并不总是严格纠错；面对明星科学家、高影响因子论文和机构声誉，有时会选择沉默、拖延甚至包庇 |

### 四、第四部分：开放科学与改革方案

```text
科学自我纠错机制重建：
研究预注册（登记设计与分析计划 → 减少事后解释与p值操纵）
    ↓
鼓励复现研究（重复验证成为有价值的学术贡献）
    ↓
开放数据与代码（过程可检查、可复算、可复用）
    ↓
改进同行评议（引入专业统计审查与方法审查）
    ↓
降低影响因子崇拜（重质量、透明度、可复现性）
    ↓
抑制媒体与机构炒作（避免初步结果包装成"颠覆性突破"）
```

### 五、应用场景与未来变化

**应用场景：**

| 场景 | 用法 |
| :--- | :--- |
| 科研训练 | 帮助研究生和青年研究者识别 p 值操纵、选择性报告、数据共享不足等问题 |
| 论文阅读 | 看到"重大突破"新闻时，先问样本量、是否预注册、是否被重复、数据是否公开 |
| 科研评价改革 | 为"破四唯"、重视研究质量与可复现性提供现实依据 |
| 公众理解科学 | 区分"科学方法本身"和"当前科研制度问题"，避免走向"科学完全不可信"的极端 |
| 媒体传播 | 提醒科技报道减少夸大标题，保留不确定性、局限性和复现状态 |

**未来可能的变化：**

- **开放科学进一步普及**：预注册、开放数据、开放代码可能成为更多期刊和基金项目的常规要求；
- **复现研究价值提升**：重复验证、阴性结果和数据质量审查可能获得更多发表渠道和职业认可；
- **AI 既可能帮助也可能加剧问题**：可辅助检测图片篡改、文本抄袭和异常数据，也可能被用于批量生成低质或问题论文；
- **撤稿与学术监督更频繁**：问题论文被识别的速度可能加快，但需避免"猎巫式"误伤；
- **科研评价更重质量**：影响因子、论文数量和 headline 式突破的权重可能下降，透明度、可复现性和长期贡献更受重视。

### 六、专业名词释义

| 术语 | 英文 | 核心概念 | 来源/背景 | 解决什么问题 |
| :--- | :--- | :--- | :--- | :--- |
| **复现危机** | Replication Crisis | 大量研究结果无法被重复验证的学科性危机 | 心理学/医学方法学 | 揭示科研可靠性问题 |
| **p 值操纵** | p-Hacking | 通过调整分析方法使结果达到显著水平的做法 | 统计推断 | 识别隐蔽的造假 |
| **选择性报告** | Selective Reporting | 只报告有利结果的报告习惯 | 科研伦理 | 保障证据完整 |
| **发表偏倚** | Publication Bias | 期刊偏好发表阳性结果导致的系统性偏差 | 元科学 | 解释阴性结果埋没 |
| **效应量** | Effect Size | 量化效应大小的统计指标 | 统计推断 | 评估结果的实际意义 |
| **预注册** | Preregistration | 研究前登记设计与分析计划的做法 | 开放科学 | 减少事后解释 |
| **同行评议** | Peer Review | 由同行专家审查论文的制度 | 学术出版 | 过滤明显问题 |
| **影响因子** | Impact Factor | 期刊平均被引次数的指标 | 文献计量学 | 评价期刊影响力 |
| **开放科学** | Open Science | 公开数据、代码与过程的科研范式 | 科学改革运动 | 提升可复现性 |
| **元科学** | Metascience | 以科学研究本身为对象的研究领域 | 科学哲学 | 研究科研制度 |
