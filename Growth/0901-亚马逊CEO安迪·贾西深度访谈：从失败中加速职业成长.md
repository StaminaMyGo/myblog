# 亚马逊 CEO 安迪·贾西深度访谈：从失败中加速职业成长

:::: tip 本文导读
受访者为亚马逊现任 CEO 安迪·贾西（Andy Jassy），AWS 的核心缔造者。访谈全程围绕「失败的价值」展开，从个人职业成长、组织效率管理、客户导向创新、科学决策方法四个维度，拆解把失败从「职业绊脚石」转化为「成长加速器」的方法论。以下内容按「总结—背景—核心观点—延伸—现实意义」重排。
::::

## 一、全文总结

1. **失败是成长的默认迭代单元**：有价值的教训几乎都来自失败；从未失败，说明探索的边界还不够。
2. **组织速度取决于领导层意志，而非规模**：冗余流程需要被主动识别并剔除，新业务应以小团队低成本启动。
3. **决策采取双轨制**：以客观数据为基础，同时保留基于客户洞察做出前瞻判断的空间；多数决策在约 70% 信息完备时即可推进。
4. **创新从客户真实痛点出发**：客户未必能说明该做什么产品，但会清晰表达不满与困境。
5. **个人成长方法**：早期用排除法探索赛道；遭遇失败不逃避；保持终身学习；掌控自己能掌控的部分。

### 2.2 三个被反复讨论的现实困境

- **对失败的负面认知**：失败被视为能力不足的证据，导致回避探索、掩盖问题；
- **大企业的官僚化**：规模扩大后流程叠加，流程本身取代业务目标成为工作阻碍；
- **职业路径的「一步到位」焦虑**：认为必须在早期选定终身方向，任何弯路都是损失。

## 三、核心观点阐释

### 3.1 底层认知重构：迭代式成长

贾西提出的核心逻辑是 **Iterating from failure（迭代式成长）**：

1. **失败是成长的必经之路**：只要在做创新与探索，就必然伴随失败。如果从未失败，只能说明探索的边界还远远不够。
2. **面对失败的正确姿态**：不推诿责任，真正聚焦解决问题；不陷入自我否定，而是完成「问题拆解 → 原因萃取 → 经验迁移」的完整闭环，把每次失败的收获落地到下一次行动。
3. **成长的本质是持续迭代**：无论产品还是人，都不存在「一次性完美」的状态，都需要通过反复试错、调整与优化逐步进阶。

### 3.2 组织效率：大公司如何对抗官僚化

#### 主动根除官僚主义

企业规模扩大过程中，管理者出于风险管控与权责划分会不断叠加流程，最终流程本身取代业务目标成为阻碍。贾西的判断是：**公司的行动速度与规模无关，只和领导层的意志有关**。管理者必须主动识别并剔除无效流程与冗余审批，让团队精力回归价值创造——不能为了规避少量风险，就让整个组织为流程内耗。

#### 小团队启动，低成本快速试错

AWS 在起步阶段仅由 13 人的小团队搭建。新项目不需要在初期就配备几十上百人的团队：

- 用精简人力先打造能击中核心需求的最小可行版本，快速投入市场验证；
- 验证通过后再逐步扩大资源投入。

这一模式的试错成本更低、迭代速度更快，优于大兵团闭门造车。

#### 决策与效率机制

| 机制 | 具体做法 |
| --- | --- |
| 决策速度 | 大多数决策不需要 100% 信息完备，掌握约 70% 信息即可推进，后续依据市场反馈动态调整 |
| 组织精简 | 持续优化组织架构，打通一线到决策层的反馈通道，让真实问题被快速响应 |
| 效率优化 | 针对每个环节做专项优化，持续压缩时间损耗 |

#### 双轨决策：数据驱动 + 文化自信

好的决策既不是唯经验论，也不是唯数据论：

- **数据基础**：用客观数据验证假设（如远程办公效率、业务健康度），避免主观偏差；
- **战略自信**：敢于基于客户洞察与行业判断，做出数据暂时无法支撑的前瞻性创新决策。

### 3.3 创新逻辑：从客户痛点出发

**客户痛点是创新的原点**。很多时候客户不会直接说明该做什么产品，但会清晰表达自己的不满与困境。创新者的任务是穿透表面诉求，找到真实痛点，再围绕痛点设计方案，而不是拿着技术找场景。

**从失败中演化出的新范式：生成式购物（Generative Shopping）**

- 传统电商逻辑：用户搜索 → 平台展示商品，本质是**人找货**；
- 生成式购物：用户表达需求 → 平台给出解决方案，把「搜索」变为「对话」，使零售交互从人找货升级为服务找人。

这一范式并非凭空设计，而是从过往的业务试错与失败中迭代出来的。

### 3.4 个人职业成长方法

#### 职业早期：用排除法找到赛道

贾西在加入亚马逊之前，尝试过体育广播、体育节目制作、高中足球教练、高尔夫零售店销售、产品经理、投资银行，还创办过两家公司，直到接近 30 岁才正式加入亚马逊。他的核心建议是：**弄清楚自己「不想要什么」，与弄清楚「想要什么」价值同等**。年轻人不必在二十几岁就强迫自己定好终身方向，多尝试不同领域与角色，反而能更快找到匹配自身热情与天赋的方向。

#### 遭遇失败：不要逃避

他分享了职业生涯中一次重大项目失败的经历：项目失利后本想避开与贝索斯的会面，最终选择主动面对，而贝索斯没有先问责业务结果，反而先关心他的个人状态。由此总结出两条准则：

1. **不要躲起来**：回避领导者只会消耗已有信任；坦诚复盘问题并给出改进方案，反而能重建他人对你能力的认可。
2. **不要把失败等同于个人否定**：失败只是单次事件的结果，不是对能力的终审判决。不要把每次尝试与每次评价都当成「通过／失败」的人生考核。

#### 长期竞争力：终身学习

很多人会因需要重新学习而感到窘迫，认为「承认不懂」是软弱的表现。贾西的判断相反：**在快速变化的商业环境中，停止学习的那一刻，就是职业开始走下坡路的时刻**。保持高「提问商（WhyQ）」——多问「为什么」与「为什么不」——通过深度提问拆解问题本质，是保持学习能力的核心方法。

#### 构建职业口碑：掌控能掌控的事

职业发展中有很多不可控因素，但以下素质完全由自己决定：是否足够努力、是否可靠、是否愿意协作、是否能持续把事情做好。这些基础品质最终决定了机会的上限，以及他人愿意与你合作的程度。

#### 给 Z 世代的建议

当下的年轻人面临前所未有的职业压力，总觉得要早早选对赛道、不能走弯路。贾西认为这属于不必要的内耗：没有人的职业是一次选择定终身的，每个人都有权不断改写自己的职业故事；真实的职业世界本就是持续试错与调整的过程，接受这种不确定性反而能走得更远。

## 五、落足当今的现实意义

1. **重新定义失败的信息价值**：在探索性工作中，失败提供的是关于边界的信息——哪些路径不通、哪些假设不成立。把失败视为信息而非判决，是提高探索效率的前提。
2. **流程需要定期审计**：流程为管控风险而生，但会随时间自我强化并取代目标。定期识别并剔除不再产生价值的审批与汇报，是保持组织速度的必要动作。
3. **决策不必等待完备信息**：等待 100% 信息往往意味着错过窗口。把决策分为可逆与不可逆两类：可逆决策在 70% 信息时快速推进，不可逆决策才投入更多论证成本。
4. **用排除法降低选择焦虑**：职业方向不一定要在早期确定。通过尝试明确「不想要什么」，同样在缩小搜索空间，且试错成本更低。
5. **坦诚是最高效的信任修复方式**：出现问题时主动复盘、给出方案，比回避更能保住信任；回避消耗的是长期积累的信用。

:::: tip 一句话总结
失败不是成长的障碍，而是成长的单位；前提是完成「拆解—萃取—迁移」的闭环，把单次结果转化为下一次行动的输入。
::::

| 名词 | 英文原文 | 释义 |

| 迭代式成长 | Iterating from failure | 以失败与试错为基础，通过复盘、萃取、迁移经验实现持续进步的成长模式 |
| 生成式购物 | Generative Shopping | 基于生成式 AI 的新型零售交互范式，把「人搜索商品」升级为「对话式需求满足」 |
| 提问商 | WhyQ（Why Quotient） | 持续提出「为什么」「为什么不」的能力，通过深度提问拆解问题本质、挖掘根本原因 |
| 数据驱动决策 | Data-Driven Decision Making | 以客观业务数据为核心依据进行决策，减少主观经验偏差的方法论 |
| 官僚主义损耗 | Bureaucratic Drag | 企业规模扩大后，冗余流程与多层审批带来的效率下降、创新变慢的负面效应 |
| 最小可行产品 | MVP（Minimum Viable Product） | 用最少功能实现核心价值，快速投入市场验证需求的产品开发策略 |
| 逆向工作法 | Working Backwards | 从客户需求出发倒推产品设计与业务流程，而非从技术和现有资源出发 |
