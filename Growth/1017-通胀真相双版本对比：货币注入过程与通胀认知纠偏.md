# 通胀真相双版本对比：货币注入过程与通胀认知纠偏

《通胀真相》这个书名对应两本立场截然不同的书。最可能指的是穆瑞·罗斯巴德的那本（2024 年人大社新出中译本），它是奥地利学派货币理论的经典。

> 核心命题：罗斯巴德把通胀看作"货币注入的过程本身"而非物价上涨——物价上涨只是后果，真正的通胀是有人凭空创造新货币，并借此在别人还没反应过来之前掠夺购买力。多诺万版则是对投资者常见的通胀直觉进行纠偏。

---

### 一、罗斯巴德版《通胀真相》

罗斯巴德的独特之处在于：**他不把通胀看作"物价上涨"，而是看作"货币注入的过程本身"**。物价上涨只是后果，真正的通胀是有人凭空创造了新货币，并借此在别人还没反应过来之前掠夺购买力。

| 章 | 核心观点 |
| :--- | :--- |
| **第一章 导言** | 货币问题的核心困惑：政府该注入货币还是抽出货币？本书用货币发展史作为思想工具，理解通胀、通缩与经济周期 |
| **第二章 自由社会中的货币** | 推演货币的"自然起源"：从以物易物到间接交换，货币是市场自发选择的结果，而非政府发明；为批判政府干预奠定逻辑基础——如果货币本该由市场提供，政府垄断货币本身就是问题之源 |
| **第三章 政府干预货币** | 全书批判的起点。政府通过铸币厂垄断、降低货币成色、建立中央银行、脱离金本位等层层递进手段，逐步取消了对通货膨胀的限制。**格雷欣法则**（劣币驱逐良币）被重新解释为政府强制下的现象，而非市场规律 |
| **第四章 西方货币体系的崩溃** | 用九个阶段梳理 1815 年至今的货币史：古典金本位 → 一战 → 金汇兑本位 → 布雷顿森林体系 → 1971 年彻底转为法定货币。结论：货币体系在制度层面持续劣化，通胀加速是结构性必然 |

```text
罗斯巴德式通胀链条：
政府垄断货币 → 降低成色/央行扩张 → 新货币凭空注入
    ↓
新货币先到者先受益（掠夺购买力）
    ↓
物价上涨（后果而非本体）
    ↓
金本位约束 → 法定货币（1971）→ 结构性通胀加速
```

### 二、保罗·多诺万版《通货膨胀的真相》

另一本同名书（保罗·多诺万，瑞银全球经济学家）立场完全不同，更像一本给投资者的"通胀认知纠偏手册"。它的核心主张是：**大多数人对通胀的直觉都是错的**。

| 都市传说 | 纠偏结论 |
| :--- | :--- |
| **"印钞必然导致通胀"是错的** | 2008 年后大放水并未引发高通胀，因为流动性偏好上升、货币流通速度下降，印钞本身不必然制造通胀 |
| **"黄金能对冲通胀"是历史误会** | 金本位在中短期内同样引入不确定性，且供给增速跟不上需求，带有通缩偏向 |
| **"通胀数据造假"被夸大了** | 调整方法虽有争议，但不太可能大幅改变数字 |
| **"通胀是外国人的错"站不住脚** | 一国货币政策对别国通胀的影响远比想象中小 |
| **"通胀能化解政府债务"是迷思** | 5%–30% 的通胀反而会因"通胀不确定性溢价"加重债务负担 |

### 三、两版对比

| 维度 | 罗斯巴德版 | 多诺万版 |
| :--- | :--- | :--- |
| **立场** | 奥地利学派 | 主流经济学家 |
| **核心问题** | 通胀是什么（本体论） | 通胀直觉哪些是错的（认知纠偏） |
| **分析对象** | 货币制度史 | 投资认知 |
| **结论指向** | 政府垄断货币是问题之源 | 用概率与数据重新校准通胀判断 |

### 四、专业名词释义

| 术语 | 英文 | 核心概念 | 来源/背景 | 解决什么问题 |
| :--- | :--- | :--- | :--- | :--- |
| **奥地利学派** | Austrian School | 强调市场自发秩序与政府干预批判的经济学流派 | 门格尔/米塞斯/罗斯巴德 | 分析货币的政府来源问题 |
| **通胀** | Inflation | 货币供给扩张导致购买力稀释的过程 | 货币经济学 | 界定通胀本体 |
| **格雷欣法则** | Gresham's Law | 劣币驱逐良币的现象 | 货币史 | 解释强制货币下的扭曲 |
| **金本位** | Gold Standard | 以黄金为货币锚的制度 | 货币制度史 | 追溯约束机制 |
| **金汇兑本位** | Gold Exchange Standard | 以可兑换黄金的外汇为储备的制度 | 布雷顿森林体系前史 | 理解制度演化 |
| **布雷顿森林体系** | Bretton Woods System | 二战后以美元-黄金为核心的固定汇率体系 | 1944 年布雷顿森林会议 | 理解 1971 年崩溃前史 |
| **法定货币** | Fiat Money | 无内在锚定、靠政府法令流通的货币 | 现代货币制度 | 界定结构性通胀条件 |
| **流动性偏好** | Liquidity Preference | 人们持有现金的倾向 | 凯恩斯 | 解释放水未通胀 |
| **货币流通速度** | Velocity of Money | 货币单位时间内转手的次数 | 货币数量论 | 解释通胀传导 |
| **通胀不确定性溢价** | Inflation Uncertainty Premium | 通胀不确定带来的额外风险补偿 | 金融定价 | 解释债务负担加重 |
