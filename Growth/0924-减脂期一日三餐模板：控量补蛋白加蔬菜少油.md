# 减脂期一日三餐模板：控量、补蛋白、加蔬菜、少油

> 按你现在的习惯设计：不强迫吃米饭，晚上可以吃水饺或葱油面，但要"控量 + 补蛋白 + 加蔬菜 + 少油"。
>
> 核心公式：
>
> **每餐 = 1 掌蛋白质 + 2 拳蔬菜 + 1 拳主食 + 少量好油**

早餐建议不要长期只吃三分饱，**5～7 分饱更稳**，否则容易中午暴食、掉肌肉。午餐 7～8 分饱，晚餐 7 分饱，睡前 3 小时吃完。

---

## 一、一日三餐模板

### 早餐（约 300～350 kcal，5～7 分饱）

选一个组合：

```text
组合 A：水煮蛋 2 个 + 无糖豆浆 300ml + 燕麦 30g/全麦面包 1 片 + 小番茄或黄瓜一把
组合 B：无糖希腊酸奶 150g + 水煮蛋 1 个 + 蓝莓一小把 + 全麦面包 1 片
组合 C：豆腐脑 1 碗 + 鸡蛋 1 个 + 凉拌黄瓜/菠菜 + 玉米半根
```

重点：**先吃蛋/奶/豆，再吃主食**。不要只喝粥或只吃水果。

### 午餐（约 450～550 kcal，7～8 分饱）

| 组分 | 分量 |
| :--- | :--- |
| 蛋白质 | 鸡胸/鱼/虾/瘦牛肉/豆腐 120～150g |
| 蔬菜 | 西兰花、彩椒、蘑菇、菠菜、生菜等 250～300g |
| 主食 | 红薯/玉米/糙米/荞麦面，熟重约 100～150g，或半拳到一拳 |
| 油 | 5～10g，少油炒或水煮后拌 |

示例：香煎鸡胸 120g + 西兰花炒蘑菇 250g + 蒸红薯 150g + 橄榄油 5g。

### 晚餐（约 400～500 kcal，7 分饱）

**方案 A：吃水饺**

```text
- 水饺 6～8 个，选瘦肉/虾仁/蔬菜馅，不煎
- 蔬菜一大盘：凉拌菠菜、木耳、黄瓜、番茄、生菜 300g
- 加豆腐 100g 或鸡蛋 1 个，补蛋白
- 蘸料：醋 + 蒜 + 生抽，少放辣油/香油
```

**方案 B：吃葱油面/面片**

```text
- 面量减到半份到 2/3 份；如果"8 片"是葱油饼/面片，通常偏多，建议减到 2～3 片或半份
- 加虾仁 100g/鸡胸 100g/鸡蛋 2 个
- 加青菜 300g
- 葱油减半，不再额外加香油
```

**方案 C：不吃主食**

```text
- 鱼/虾/豆腐 150g + 蔬菜 300g + 少量玉米/红薯 50～100g
```

### 加餐（可选）

下午饿的话：无糖酸奶 1 杯 / 苹果 1 个 / 坚果 10g / 水煮蛋 1 个。晚上尽量不加餐。

## 二、关键规则

| # | 规则 | 说明 |
| :--- | :--- | :--- |
| 1 | 水饺和葱油面不是禁忌 | 一周 2～3 次就够，不要天天吃 |
| 2 | 葱油面油高、碳水高 | 面减半、油减半、菜和蛋白加倍 |
| 3 | 水饺 8 个约 320～400 kcal | 如果还吃葱油面，当天午餐主食要减半 |
| 4 | 进食顺序 | 蔬菜 → 蛋白 → 主食，细嚼慢咽 20 分钟 |
| 5 | 生活习惯 | 每天喝水 1.5～2L，睡 7 小时，每周力量训练 2～3 次 |
| 6 | 减脂速度 | 每周 0.3～0.8kg。头晕、乏力、掉头发说明吃太少，要加主食和蛋白 |

::: warning 提示
若要精确到"克"和"热量"的三餐计划，需要提供：身高、体重、年龄、性别、日常活动量、目标体重。
:::
