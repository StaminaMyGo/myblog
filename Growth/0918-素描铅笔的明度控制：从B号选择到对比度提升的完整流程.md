# 素描铅笔的明度控制：从 B 号选择到对比度提升的完整流程

不同 B 型号的铅笔，本质上是不同"黑度/软度"的明度层级：**B 数越大，铅芯越软、越黑；H 数越大越硬、越浅**。提高对比度的关键不是全画都用 8B，而是**用硬铅/纸白守住最亮，用软铅逐层压出最暗，让最亮和最暗拉得更开**。

本笔记把"铅笔型号—明度层级—作画流程"整理成可执行的操作系统，并给出从起稿到统一画面的八步标准流程。

---

## 一、铅笔型号与明度层级的对应关系

| 铅笔型号 | 软硬 | 明度特征 | 典型用途 | 使用注意 |
| :--- | :--- | :--- | :--- | :--- |
| **HB / 2H** | 硬 | 亮灰、浅、不易脏 | 起稿、细节、亮部 | 用力过猛会在纸上压出凹痕 |
| **2B / 4B** | 中等 | 中间调、灰面 | 铺大调子、暗部基础 | 最常用区间，覆盖 70% 画面 |
| **6B / 8B** | 软 | 深黑、易晕染 | 深暗部、投影根部、缝隙 | 反复擦会反光、发腻 |

::: note 只用一种铅的后果
- **只用 HB**：最暗只能到中灰，画面容易"灰"，缺乏对比。
- **一上来就用 8B**：暗部糊、反光、脏，亮部也被压暗，对比反而下降。
:::

---

## 二、核心原则：从硬到软、从浅到深、从整体到局部

素描的明度控制遵循一条不可颠倒的顺序：

```text
硬铅 ──▶ 2B/4B ──▶ 4B/6B ──▶ 6B/8B ──▶ 橡皮/硬铅 ──▶ 眯眼统一
起稿      铺大调       加深暗部      压最暗        提亮         调整
```

三个"从"字原则：

1. **从硬到软**：先硬铅起稿定形，再逐步换软铅加深，避免早期就下重手。
2. **从浅到深**：明度只允许由浅往深叠加，深了可再用橡皮救回，浅了随时可补。
3. **从整体到局部**：先分大块面（黑白灰三区），再抠细节，防止局部过早深入导致整体失衡。

---

## 三、八步标准流程

### 第 1 步：观察定调

先定光源方向，分出黑、白、灰三区：

- 标出**最亮处**：高光、纸白。
- 标出**最暗处**：投影近端、明暗交界线、物体底部、缝隙。

::: tip 定调即构图
观察定调是整个画面明度框架的"总设计图"。光源方向决定暗部朝向，明暗交界线的位置决定体积感。
:::

### 第 2 步：起形用硬铅

- 用 **HB 或 2B** 轻线起稿，线要松、要浅。
- 高光位置提前留白，不要画满。

### 第 3 步：铺大调子用 2B/4B

- 用 **2B 或 4B 侧锋**铺暗部和投影，先统一背光面。
- 亮部尽量少动，保留纸白。
- 这一步只分大块，不抠细节。

### 第 4 步：建立中间调

- 用 **2B/4B** 轻排、叠加，画灰面和过渡。
- 亮灰用 **HB/2H**。
- 中间调要丰富，否则对比会生硬。

### 第 5 步：加深暗部用 4B/6B

- 重点压：明暗交界线、投影靠近物体处、遮挡处、物体底部。
- 力度逐渐加重，排线加密。

### 第 6 步：压最暗用 6B/8B

- 只在最暗点使用：投影最深处、缝隙、深色物体核心暗部。
- 不要大面积涂死，否则画面会闷。
- 可配合炭笔，但更难控制。

### 第 7 步：提亮与调整

- 用**可塑橡皮**提高光、反光，或用 **HB/2H** 修亮部。
- 高光尽量靠纸白。
- 然后眯眼看整体，自问三个问题：最暗够不够黑？最亮够不够亮？中间调是否太灰？

### 第 8 步：统一画面

- 暗部要透气，边缘有虚实。
- 必要时再用软铅压暗关键处，再用橡皮提亮，形成"最亮—最暗"并置，对比度就出来了。

| 步骤 | 工具 | 任务 | 关键词 |
| :--- | :--- | :--- | :--- |
| 1 观察定调 | 眼睛 | 分黑白灰、定光源 | 高光、明暗交界线 |
| 2 起形 | HB/2B | 轻线起稿、高光留白 | 松、浅 |
| 3 铺大调 | 2B/4B | 侧锋铺暗部投影 | 大块、统一 |
| 4 中间调 | 2B/4B + HB/2H | 灰面与过渡 | 丰富、不生硬 |
| 5 加深暗部 | 4B/6B | 压交界线、投影近端 | 加密排线 |
| 6 压最暗 | 6B/8B | 最暗点定点压深 | 透气、不闷 |
| 7 提亮 | 可塑橡皮/HB | 高光反光、修亮部 | 眯眼检查 |
| 8 统一 | 全部 | 虚实边缘、并置对比 | 整体协调 |

## 四、完整示例：画一个苹果

| 顺序 | 工具 | 动作 |
| :--- | :--- | :--- |
| 1 | HB | 起形，标高光 |
| 2 | 2B | 铺苹果暗部、投影、背景 |
| 3 | 4B | 压明暗交界线、投影根部 |
| 4 | 6B | 压投影最深处、苹果底部 |
| 5 | 2B | 画灰面 |
| 6 | HB | 画亮灰，高光留白 |
| 7 | 可塑橡皮 | 提反光，调整边缘 |

## 五、常见错误与注意点

| 错误 | 后果 | 正确做法 |
| :--- | :--- | :--- |
| 一开始就上 8B | 暗部糊、反光、脏，对比下降 | 先铺中间调，再逐层加深 |
| 软铅反复擦 | 画面反光、发腻 | 控制笔触次数，尽量一次到位 |
| 迷信 B 号标准 | 不同品牌 B 号差异很大 | 以实际手感为准，先试笔 |
| 以为对比度 = 全黑 | 画面闷、无层次 | 靠"最亮与最暗的并置"与中间层次 |

## 六、流程总结

> **硬铅起稿 → 2B/4B 铺大调 → 4B/6B 加深暗部 → 6B/8B 压最暗 → 橡皮/硬铅提亮 → 眯眼统一调整。**

对比度的本质不是"画得黑"，而是**让最亮与最暗拉得更开、中间层次更丰富**。铅笔型号只是实现这一目标的分级工具——先守住纸白，再逐层压出黑暗，明度体系自然成立。
