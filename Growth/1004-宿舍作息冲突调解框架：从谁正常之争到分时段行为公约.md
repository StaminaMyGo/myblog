# 宿舍作息冲突调解框架：从"谁正常"之争到分时段行为公约

核心结论：**不要争论"几点睡才正常"，而要协商"几点到几点、在宿舍允许什么行为"。** 舍友一（早睡方）的睡眠需求应优先于舍友二（打游戏方）的娱乐语音需求，但舍友一也不能要求 22:00 后"绝对无声"。舍友二可以打游戏，但不能以"我必须说话"为由，让全宿舍承担噪音。

> 核心命题：作息冲突的本质不是"谁更正常"，而是"双方愿意接受哪套行为规则"。共识不是统计多数，而是**双方同意且能执行的规则**。谈判单元应从"时间段"切到"行为类型"——关灯、安静、语音分别协商。

---

### 一、先拆开问题：关灯、安静、语音是三个问题

| 子问题 | 双方立场 | 可达成共识的中间解 |
| :--- | :--- | :--- |
| **关灯** | 舍友一要求 23:00 关灯；舍友二认为 23:00 睡觉正常 | **23:00 关顶灯，改用台灯/屏幕灯** |
| **安静** | 舍友一希望安静；舍友二需要语音 | 22:00—23:00 过渡时段：低声、戴耳机、短句交流；连续语音去室外 |
| **语音** | 舍友二称"不说话侵犯权益" | 该说法不成立：他的权益是打游戏和社交，不是"在宿舍大声语音到别人睡不着"。调整时间、地点、音量不等于剥夺权益 |

---

### 二、可执行的宿舍公约模板（试行两周）

| 时段 | 行为规则 |
| :--- | :--- |
| **22:00 前** | 正常活动 |
| **22:00—23:00 过渡安静** | 舍友二可打游戏但必须戴耳机、禁止外放；语音尽量低声简短；连续指挥/开黑说话去走廊、阳台、活动室、网吧或公共区域；舍友一使用耳塞、白噪音，接受正常键盘声和屏幕光 |
| **23:00 后 静音模式** | 关顶灯，用台灯或调低屏幕亮度；舍友二可继续游戏但静音、打字、不语音、不外放；必须语音则去宿舍外；舍友一戴眼罩/耳塞，接受轻微键盘声 |

**补充条款：**

- 舍友二可换静音键盘、静音鼠标；
- 舍友二如有重要开黑，提前一天协商，安排在 22:00 前或室外；
- 违反先提醒，屡次不改找宿管/辅导员调解。

---

### 三、沟通时不要争"谁正常"

舍友二说"11 点睡才是共识"，舍友一说"我认识的人都 10 点睡"，这都不是真正共识。共识不是统计多数，而是**双方同意且能执行的规则**。可以这样谈：

> "我们不争谁作息正常。23:00 关灯可以接受。争议是 22:00—23:00 的语音。你能不能戴耳机、压低声音，连续说话去外面？我可以戴耳塞，不要求绝对无声。23:00 后你静音打字或去外面语音，我戴眼罩。试行一周，不行再找宿管。"

```text
协商话术结构：
1. 声明不争正常 → "我们不争谁作息正常"
2. 给出可接受项 → "23:00 关灯可以接受"
3. 聚焦争议点 → "争议是 22:00—23:00 的语音"
4. 对等让步 → 你戴耳机/去外面 + 我戴耳塞/不要求绝对无声
5. 设定试运行 → "试行一周，不行再找宿管"
```

---

### 四、如果双方都不让步

如果舍友二坚持"22:00—23:00 必须大声语音，23:00 后也要语音"，舍友一坚持"22:00 后绝对无声"，那这不是沟通技巧能解决的，而是生活习惯硬冲突。此时最优解是：

```text
升级路径：
1. 找宿管/辅导员/楼长第三方调解
2. 签订书面公约
3. 仍无效 → 申请调换宿舍
```

**一句话：舍友二可以打游戏，但不能在别人睡觉时持续语音；舍友一可以要求安静，但也要接受过渡时段和耳塞等妥协。能谈就定公约，不能谈就换宿舍。**
